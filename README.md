# Фасад Эксперт

Ты senior product designer и frontend-архитектор. Твоя специализация: сложные B2B системы управления производством. Ты делаешь интерфейсы, которые выглядят дорого и работают быстро: плотная информация без визуального шума, ноль лишних кликов, все состояния продуманы.

Создай прототип веб-платформы ФАСАД-РП: система управления фасадными строительными проектами с AI-агентами.

=== КОНТЕКСТ ПРОДУКТА ===

Пользователь: подрядчик по навесным вентилируемым фасадам и светопрозрачным конструкциям на многоэтажных домах. Ведет 3-5 объектов одновременно. Штат: руководители проектов, прорабы, ПТО, снабжение, проектировщики, производство, склад, генеральный директор.

Что делает система: хранит единую память по каждому объекту, читает договоры и вытаскивает из них контрольные точки, собирает ежедневные отчеты с объектов через Telegram, контролирует сроки, формирует и рассылает заявки поставщикам, ведет реестр документации.

Главный пользователь веб-интерфейса: руководитель проекта. Он открывает систему утром и за 15 секунд должен понять, что горит на четырех объектах. Прорабы и монтажники в веб не заходят, они работают в Telegram-боте.

Ключевой принцип интерфейса: это рабочий инструмент, а не дашборд для презентаций. Плотность информации важнее воздуха. Но плотность достигается типографикой и сеткой, а не мелким шрифтом.

=== ТЕХНИЧЕСКИЙ СТЕК ===

React 19 + TypeScript + Vite

Tailwind CSS v4

shadcn/ui как база компонентов

lucide-react для иконок

recharts для графиков

date-fns для дат, локаль ru

Роутинг: react-router-dom

Все данные моковые, лежат в /src/mock/. Никаких запросов к API. Структура моков должна повторять будущий формат ответов бэкенда, чтобы потом подменить одним слоем.

=== ЛЕЙАУТ ===

Три зоны.

1. Сайдбар слева, ширина 264px, сворачивается до 64px с иконками. Состояние сворачивания в localStorage не пишем, держим в React state. Темный фон всегда.

Структура сайдбара сверху вниз:

- Логотип и название системы, под ним мелко название компании-клиента

- Селектор активного объекта: выпадающий список со всеми объектами плюс пункт "Все объекты". Это ключевой элемент, он фильтрует весь интерфейс

- Основная навигация, сгруппирована с подписями групп

- Внизу: карточка текущего пользователя с ролью, переключатель темы, выход

2. Верхняя панель, высота 56px, прилипает при скролле:

- Хлебные крошки слева

- Глобальный поиск по центру, с подсказкой Ctrl+K, ищет по объектам, задачам, документам, поставщикам

- Справа: кнопка спросить агента, колокольчик уведомлений со счетчиком, аватар

3. Контент. Максимальная ширина 1680px, центрируется на широких экранах.

=== ПЕРЕЧЕНЬ ЭКРАНОВ ===

1. ДАШБОРД

Ответ на вопрос "что горит прямо сейчас". Открывается по умолчанию.

- Строка из 5 плиток: активных объектов, задач просрочено, отчетов не сдано вчера, заявок без ответа поставщика, отклонение план-факт в процентах. У каждой плитки дельта к прошлой неделе.

- Блок "Требует внимания": лента событий, отсортированная по критичности. Каждая строка это иконка типа, текст, объект, время, кнопка действия. Типы: просрочка задачи, поставка под угрозой, прораб не сдал отчет, договорной срок через N дней, дефицит материала.

- Карточки объектов, по одной на объект: название, адрес, процент готовности с прогресс-баром, срок по договору, статус светофором, три ключевые цифры.

- График план-факт по объемам за 30 дней, две линии.

- Правая колонка: последние отчеты с объектов, компактная лента с миниатюрами фото.

2. ОБЪЕКТЫ, список

Таблица с фильтрами и переключателем таблица/карточки. Колонки: объект, заказчик, договор, срок, готовность, РП, статус, бюджет. Строка кликабельна.

3. ОБЪЕКТ, карточка

Шапка: название, адрес, заказчик, номер и дата договора, сумма, срок, РП, статус. Справа кнопки действий.

Вкладки:

- Обзор: контрольные точки договора таймлайном, ключевые цифры, риски

- График: календарно-сетевой график, захватки по этажам, план и факт

- Задачи: задачи этого объекта

- Отчеты: лента отчетов прорабов с фото

- Документы: реестр документов объекта

- Снабжение: потребность в материалах, заявки, статусы поставок

- Захватки: визуализация фасада, разбитого на захватки, с процентом готовности каждой

- Финансы: бюджет, факт, допработы, прогноз

- Журнал: все действия по объекту

4. ЗАДАЧИ

Два режима: таблица и канбан по статусам. Фильтры: объект, ответственный, статус, срок, источник. Источник задачи важен: создана вручную или сгенерирована агентом из договора, у второго типа значок и ссылка на пункт договора.

5. ОТЧЕТЫ С ОБЪЕКТОВ

Лента отчетов, пришедших из Telegram. Каждая карточка: аватар и имя прораба, объект, захватка, этаж, вид работ, объем с единицей измерения, фото галереей, отмеченные проблемы, время, статус проверки.

Ключевой элемент: если отчет пришел голосом, показывать плеер с оригиналом и рядом структурированные поля, которые вытащил агент. Каждое поле редактируемое, с индикатором уверенности агента. Это главный экран доверия к системе.

Действия: принять, отредактировать, вернуть прорабу с комментарием.

6. ГРАФИК РАБОТ

Диаграмма Ганта. Уровни вложенности: объект, этап, захватка, работа. План и факт двумя полосами. Критический путь выделен. Перетаскивание не нужно, это прототип, но курсор и подсветка должны намекать на интерактивность.

7. ДОКУМЕНТЫ

Реестр всех документов. Колонки: название, тип, объект, кто загрузил, дата, статус обработки агентом, размер. Типы: договор, допсоглашение, проектная документация, замерная карта, акт, КС-2, КС-3, сертификат, письмо.

Зона загрузки drag and drop наверху. При загрузке показывается прогресс обработки агентом: загружен, распознается, извлекаются данные, готов.

8. ДОГОВОРЫ И КОНТРОЛЬ

Самый важный экран для демонстрации ценности агента. Двухпанельный вид.

Слева: просмотр PDF договора.

Справа: список полей, которые вытащил агент. Стороны, предмет, сумма, аванс, сроки начала и окончания, этапы, контрольные точки, штрафы и пени, гарантийный срок, порядок приемки.

У каждого поля: значение, кнопка перехода к странице документа, подсветка цитаты в PDF, индикатор уверенности агента цветом, кнопка подтвердить или исправить.

Внизу: кнопка "Создать задачи из контрольных точек" с превью того, какие задачи будут созданы.

9. ЗАЯВКИ И ЗАКУПКИ

Список заявок. Каждая заявка: объект, позиции с количеством, кому разослано, сколько ответов получено, лучшая цена, срок поставки, статус.

Экран создания заявки: выбираешь объект, добавляешь позиции из справочника номенклатуры, система сама подбирает поставщиков по категории, показывает список с галочками, генерирует текст письма, дает превью перед отправкой.

Экран сравнения ответов: таблица, поставщики в колонках, позиции в строках, цены в ячейках, лучшая цена подсвечена, итог внизу.

10. ПОСТАВЩИКИ

Карточки или таблица. Поля: название, категории материалов, контакты, средний срок ответа, средний срок поставки, число выполненных заявок, рейтинг надежности. Карточка поставщика с историей заявок.

11. АГЕНТЫ

Список агентов системы. Каждый агент это карточка: название, что делает одной строкой, статус активен или выключен, число запусков за неделю, средняя точность, средняя стоимость запуска.

Агенты: парсер договоров, обработчик отчетов с объекта, генератор задач, контролер сроков, формирователь заявок, аналитик сводок.

Карточка агента: описание, настройки, системный промпт в редакторе, инструменты которыми пользуется, история запусков, тестовая площадка где можно прогнать на файле и посмотреть результат.

12. БАЗА ЗНАНИЙ

Материалы, на которых агенты строят ответы: регламенты компании, типовые узлы, альбомы технических решений, шаблоны документов, нормативы. Список с типом, размером, датой индексации, статусом.

13. ЖУРНАЛ АГЕНТОВ

Лента всех запусков агентов. Строка: время, агент, что обрабатывал, длительность, результат, стоимость в токенах и рублях. Раскрытие строки показывает вход, шаги рассуждения, вызванные инструменты, выход. Фильтр по агенту и по успешности.

14. АНАЛИТИКА

Отклонения план-факт по объектам, динамика выполнения объемов, дисциплина отчетности по прорабам, статистика по срокам поставок, экономия времени.

15. СПРАВОЧНИКИ

Вкладки: номенклатура материалов, категории, единицы измерения, виды работ, типы захваток, статусы, шаблоны документов, шаблоны писем поставщикам.

16. ПОЛЬЗОВАТЕЛИ И РОЛИ

Таблица пользователей: ФИО, роль, объекты, Telegram привязан или нет, последняя активность, статус.

Отдельная вкладка ролей: матрица прав. Строки это разделы системы, колонки это роли, ячейки это чтение, запись, нет доступа. Роли: генеральный директор, руководитель проекта, прораб, ПТО, снабжение, финансы.

17. ИНТЕГРАЦИИ

Карточки интеграций со статусом подключения: Telegram-бот, корпоративная почта IMAP и SMTP, Яндекс.Диск, Яндекс.Таблицы, языковая модель, распознавание речи. У каждой: статус, дата последней синхронизации, кнопка настроить, кнопка проверить соединение.

Отдельно карточки с пометкой "запланировано": 1С, ЭДО, CRM. Они видны, но неактивны. Это важно, клиент должен видеть, что путь предусмотрен.

18. ЖУРНАЛ ДЕЙСТВИЙ

Аудит-лог. Время, пользователь, действие, объект, детали, IP. Фильтры и экспорт.

19. НАСТРОЙКИ

Профиль компании, объекты по умолчанию, правила эскалации, расписание напоминаний, шаблоны уведомлений, часовой пояс, рабочий календарь.

=== СКВОЗНЫЕ ЭЛЕМЕНТЫ ===

Панель агента. Кнопка в шапке открывает выезжающую справа панель шириной 420px. Внутри чат: пользователь пишет вопрос в свободной форме, агент отвечает по данным системы. Каждый ответ содержит ссылки на источники: документ и страницу, отчет, задачу. Панель не перекрывает контент, а сжимает его.

Индикатор уверенности агента. Единый компонент. Три уровня: высокая уверенность зеленая точка, средняя желтая, низкая красная с обязательной пометкой "требует проверки". Применяется везде, где данные извлечены агентом, а не введены человеком.

Значок происхождения данных. Маленькая иконка рядом с любым полем, которое заполнил агент. При наведении тултип: какой агент, когда, из какого источника. Это ключевой элемент доверия, не пропусти его.

Пустые состояния. Для каждого списка нарисуй осмысленное пустое состояние: иконка, заголовок, объяснение, кнопка первого действия. Не пиши "Нет данных".

Состояния загрузки. Скелетоны, повторяющие структуру контента. Не спиннеры.

Состояния ошибки. Понятный текст и кнопка повтора.

Уведомления. Выпадающая панель из колокольчика, сгруппированы по дням, непрочитанные подсвечены.

Командная палитра. Ctrl+K открывает поиск по всей системе с группировкой результатов по типу.

=== ЧЕГО НЕ ДЕЛАТЬ ===

Не используй градиенты на кнопках и карточках.
