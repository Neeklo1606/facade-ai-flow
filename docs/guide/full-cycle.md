# Полный цикл: от сметы до табеля и Excel

Документ для СЛАВЯНСКГАЗСТРОЙ и для команды. Шаги и экраны совпадают в мобильной версии и на
компьютере. На компьютере деталь открывается панелью справа, на телефоне — шторкой на весь экран.
Основание: созвон 17.11.2026 и бриф «три промпта до рабочего сервиса».

## Кто что делает

| Роль | Устройство | Главное действие |
| --- | --- | --- |
| Оксана, менеджер | компьютер | загружает сметы, назначает разделы, проверяет время и долю, закрывает неделю, выгружает Excel |
| Руководитель | телефон и компьютер | смотрит неделю и выработку, загружает и подтверждает сметы, закрывает неделю |
| Бригадир | телефон | вносит время за 5 касаний, отвечает «Работы по разделу закончены?» |

## Шаг 1. Загрузить сметы

**Где:** «Справочники → Сметы», блок «Папка смет».

1. Перетащить файлы .xls и .xlsx в блок или нажать «Выбрать файлы». Можно несколько сразу,
   до 20 файлов по 20 МБ.
2. У каждого файла появляется статус: «Распознана», «Нужна проверка» с причиной или
   «Не распознана» с причиной.
3. Тот же файл второй раз: «Уже загружена», новой версии нет.
4. Изменённый файл той же сметы: «Новая версия 2, изменились разделы 3 и 7».

**Телефон:** блок тот же, «Выбрать файлы» открывает файлы телефона.

**Способ загрузки** (вопрос из созвона): сейчас готовы три пути.
- В систему напрямую: рекомендуем, работает сегодня.
- Через папку Яндекс Диска: код есть, включается флагом, когда будет доступ.
- С рабочего компьютера: это тот же путь, что «в систему».
Нужно решение СЛАВЯНСКГАЗСТРОЙ.

## Шаг 2. Проверить, что система вытащила из сметы

**Где:** нажать на файл → карточка сметы.

| Что | Откуда в файле |
| --- | --- |
| Наименование работ и объекта | строка шапки, номер строки показан рядом |
| Адрес: населённый пункт, улица, дом, квартира | из наименования |
| Номер сметы, КП или договора, дата, вид работ | строки шапки |
| Разделы: итог, материалы, работы без материалов, ФОТ, НР, СП | блок «Итоги по разделу» |
| Нормативные трудозатраты раздела, чел.-ч | итоги раздела |
| Опрессовка | раздел «Испытания» целиком или строки ГЭСН19-01-015 и похожие внутри раздела |
| Сверка | сумма разделов против «Всего без НДС»; расхождение подсвечено жёлтым |

Чего нет в файле, то пустое с причиной: система не угадывает.

## Шаг 3. Создать карточку объекта

**Где:** карточка сметы → «Создать объект» или «Прикрепить».

1. Если номер сметы или адрес совпал с существующим объектом, система предлагает «Прикрепить»:
   второй такой же объект не создаётся.
2. Если объекта нет, «Создать объект» открывает поля из шапки: адрес, номер, вид работ.
   Человек проверяет и сохраняет.
3. Объект получает разделы сметы и ссылку на исходный файл.

## Шаг 4. Назначить разделы бригадам

**Где:** «Справочники → Объекты» → объект → блок «Разделы сметы».

1. У каждого раздела видны стоимость работ, начислено, остаток, доля, норматив и бригады.
2. «Назначить бригаду» → бригада, с какого по какое число → «Назначить».
3. Раздел 3 бригаде 2, раздел 5 бригаде 4: каждая бригада видит только свой раздел.

## Шаг 5. Бригадир вносит время

**Где:** телефон бригадира, «Сегодня» → «Добавить время».

1. Объект из графика уже выбран. Раздел подставляется сам, если он один; если их несколько,
   бригадир выбирает.
2. Время: кнопками 08:00 и 17:00 или текстом «с 8 до 17, обед час». Перерыв как вчера.
3. «Проверить» → «Отправить». Повторная отправка той же записи дубль не создаёт.
4. Вопрос «Работы по разделу на объекте закончены?» Да / Нет, можно пропустить.

Без сети запись сохраняется на телефоне и уходит, когда связь вернётся.
Бот в MAX включается, когда у организации будет аккаунт и бот (шаг созвона 2).

## Шаг 6. Оксана проверяет время и долю

**Где:** «Проверка».

1. Сверху новые записи. Записи с замечаниями помечены: пересечение времени, повторный выезд,
   состав больше бригады.
2. Нажать на запись → деталь: время работы «7 ч 50 мин», перерыв, состав, человеко-часы.
3. Блок «Доля и начисление»: «Доля выполнения раздела: предложено 45 % (по нормативу) ·
   было 20 %», сумма и остаток раздела. Принять как есть или ввести своё число;
   «Раздел завершён» ставит 100 %. Без норматива — «Начислить вручную с причиной».
4. «Принять». Отмена в тосте 6 секунд.
5. Пакетом: отметить флажками записи → «Подтвердить выбранные». Если среди них есть записи
   с замечаниями, система покажет их список и спросит подтверждение.

На начальном этапе (договорённость созвона) Оксана проверяет каждую запись. Когда расхождений
не будет, включается автопилот: записи без замечаний принимаются сами, с замечаниями ждут
человека. Доля раздела и деньги всегда за человеком.

## Шаг 7. Табель

**Где:** «Табель».

1. По дням: сумма начислений, эффективное время, доходность часа — как в Excel заказчика.
2. Неподтверждённые записи подсвечены янтарным и в утверждённый Excel не идут.
3. Опрессовка строкой «в т. ч. опрессовка» под адресом.

## Шаг 8. Закрыть неделю и выгрузить Excel

**Где:** «Неделя» → «Закрыть неделю», «Табель» → «Выгрузить».

1. Закрыть может руководитель, когда все записи проверены или причины приняты.
2. Закрытая неделя не меняется. Исправление — через «Переоткрыть» с причиной.
3. Excel: лист «Отчёт» в структуре заказчика, лист «Записи» с разделом, СМР, опрессовкой
   и долей, лист «Как считалось».

## Что нужно от СЛАВЯНСКГАЗСТРОЙ (по созвону)

1. Проверить демо и прислать замечания по удобству.
2. Решить, кто подтверждает организацию в MAX и с какого телефона.
3. Купить домен на организацию и сервер или хостинг, дать доступы.
4. Выбрать способ загрузки смет: в систему, папка Яндекс Диска или оба.
5. Назначить, кто и до какого срока проверяет первые записи времени, и договориться,
   по каким признакам записи можно принимать автоматически.
