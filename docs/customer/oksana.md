# Инструкция менеджеру проверки

Для Оксаны. Вход по своей ссылке, роль «Менеджер проверки». Деньги решаете вы: система
предлагает, в отчёт попадает только то, что вы приняли.

## 1. Загрузить сметы

1. «Объекты» → **«Загрузить смету»**. Перетащите файлы .xls или .xlsx, можно несколько.
2. Посмотрите «Что нашли в файле»: шапка, разделы и сходимость с итогом, материалы,
   нормативные чел.-ч, объект. Чего в файле нет, так и написано («найдено 0 из 6»):
   ноль или догадку система не подставляет, такие места проверяете вы.
3. Нажмите на раздел: видны итог, материалы и номера строк файла. Так сверяется с Excel.
4. **«Дальше: объект»** → «Создать объект» (поля заполнены из шапки сметы, поправьте при
   необходимости) или «Выбрать объект», если он уже есть. Тот же файл второй раз объект
   не задвоит: система скажет, что файл уже загружали.

## 2. Назначить бригады

На шаге «Бригады» выберите бригаду для каждого раздела или одну «Всем разделам одну
бригаду». Разным разделам можно разные бригады. Внизу «Назначено N из N» → **«Открыть объект»**.

## 3. Проверить и подтвердить время

1. **«Проверка»**: сверху новые записи, метки показывают, на что смотреть (пересечение
   времени, состав больше бригады, нет подтверждённой стоимости).
2. Откройте запись, сверьте время и сумму:
   - **«Принять»**: запись идёт в отчёт;
   - **«Исправить»**: меняете время с причиной, причина остаётся в истории;
   - **«На уточнение»**: вопрос уходит бригадиру.
3. Записи без замечаний: **«Принять N без замечаний»** одной кнопкой.

## 4. Выгрузить Excel

«Табель» → **«Выгрузить»**:
- **Excel утверждённый**: только принятые записи. Это файл для расчёта;
- **Excel черновик**: всё, непроверенные помечены. Для сверки, не для оплаты.

Неделю закрывает руководитель на экране «Неделя». Закрытая неделя не меняется.

## Если что-то не так

- Сумма не та или нет стоимости по объекту: «Сметы», источник суммы указан у каждого объекта.
- Ссылка входа не открывается: администратор выпускает новую.
- Любой другой вопрос: администратору сервиса.
