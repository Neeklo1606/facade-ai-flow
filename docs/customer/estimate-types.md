# Типы смет и что из них брать

Инструкция для разбора смет и для мастера загрузки. Составлена по двум звонкам с заказчиком
(разбор сумм СМР с менеджером проверки и её напарницей; согласование интерфейса). Суммы из
звонков сюда не переносятся: репозиторий публичный, реальные сметы лежат только в `.local/`.

Где правило не названо заказчиком прямо, оно помечено **«уточнить»**. Такие значения система
не угадывает: показывает человеку и ждёт подтверждения.

## Общее для всех смет

1. **Что за объект.** В шапке сметы есть полное наименование объекта: вид работ и адрес
   («строительство газопровода-ввода по адресу …»). Из него берутся адрес, вид работ и
   номер сметы. Карточка объекта создаётся из сметы, а не вводится вручную.
2. **Нужны не все разделы.** В смете много разделов (земля, полиэтилен, сталь, испытания…).
   Отделу Оксаны нужен раздел **«Монтаж стальных газопроводов»** и, если есть, раздел
   **испытаний (опрессовки)**. Остальные разделы относятся к другим бригадам и другому
   человеку; их назначение обсуждается отдельно (**уточнить** с напарницей Оксаны).
3. **Сумма СМР раздела** = строка «Итого по разделу …» минус строка «Материалы» этого
   раздела. Строка «Итого по смете» не берётся. В смете сумма СМР не написана: сейчас её
   считают вручную по бумажной смете и вносят в программу.
4. **Нет строки «Материалы»** в разделе — СМР равна итогу по разделу (так у испытаний).
5. **Трудозатраты (чел.-ч)** в смете есть, но это не СМР. Это часы по норме: по ним видно,
   на сколько рассчитан адрес (например, на полдня).
6. **Сумма начисления** = СМР раздела. Она уходит в отчёт за этот адрес в тот день, когда
   бригада его сделала. Адрес обычно рассчитан на один день.
7. **Не успели за день** — сумма делится пропорционально выполненному: сегодня часть
   по времени, остаток переносится на следующий день. Больше сметы начислить нельзя:
   если работ больше, будет другая смета с другой суммой.
8. **Эффективное время** — сколько бригада была на самом адресе (выехали в 9, вернулись
   в 12 — три часа), а не вся смена.
9. **Доходность часа** = сумма начисления / фактические часы. Часы сейчас выгружаются
   из 1С в Excel.
10. **Опрессовка (испытания) — отдельной строкой отчёта** на ту же бригаду: «Бригада 1 …»
    и «Бригада 1 … опрессовка» с двумя раздельными суммами. Со сталью в одну сумму
    не складывается. У опрессовки своя доходность часа.

## Тип 1. Внутренний газопровод, дополнительная газификация без осложнений

Самая простая смета. Нужен один раздел — «Монтаж стальных газопроводов».

| Что | Где в смете | Как |
| --- | --- | --- |
| Объект и адрес | шапка, полное наименование | как написано |
| Номер сметы | шапка | как написано |
| Итого по разделу | строка «Итого по разделу Монтаж стальных газопроводов» (перед следующим разделом) | число |
| Материалы | строка «Материалы» в итогах раздела | число |
| СМР | — | итого по разделу − материалы |
| Трудозатраты | итоги раздела | для плана дня, не для денег |

## Тип 2. Дополнительная газификация со сталью и испытаниями (врезка, арка на объекте)

Два нужных раздела: **сталь** и **испытания (опрессовка)**.

| Раздел | Сумма в отчёт |
| --- | --- |
| Монтаж стальных газопроводов | итого по разделу − материалы → сумма начисления |
| Испытания / опрессовка | итого по разделу; материалов обычно нет — берётся итог как есть; если строка «Материалы» есть, она вычитается |

Обе суммы относятся к одной бригаде, но в отчёте это две строки.

## Тип 3. Большая смета на много листов (несколько адресов улицы, надземный газопровод)

Итоги разделов в конце сметы, после позиций, «смело листать вниз».

| Раздел | Сумма в отчёт |
| --- | --- |
| Монтаж стальных газопроводов | «Всего по разделу» − «Материалы» (в итогах раздела четвёртая строка) |
| Испытание газопровода | отдельный раздел: минус материалы, если они есть; иначе итог по разделу |

Сталь и испытание — два раздела, всегда раздельно, это разные работы. Нужно ли отделять
испытание у любого стального газопровода или только у врезки — **уточнить** (в звонке
ответили «наверное, да»).

## Тип 4. Подземный газопровод: земля, полиэтилен, сталь

Разделы идут подряд: земляные работы, полиэтилен, сталь. Итоги разделов — в самом низу.

- Оксане относится только **«Монтаж стальных газопроводов»**: итого по разделу − материалы.
- Испытания этого типа её не касаются.
- Земля, полиэтилен и прочие разделы уходят другим бригадам и другому ответственному:
  одна смета — разные бригады. Правила по ним **уточнить** у напарницы Оксаны.

## Что делает система с каждой сметой

1. Определяет тип по разделам (есть ли сталь, испытания, земля, полиэтилен) и показывает
   его человеку: «Смета типа 2: сталь и испытания».
2. Показывает каждое извлечённое значение с номером строки файла: объект, адрес, номер,
   по каждому нужному разделу итог, материалы, СМР, трудозатраты.
3. Человек отвечает «Да, верно» или «Нет, исправить» и вводит правильное значение
   с причиной. Без подтверждения сумма в отчёт не уходит.
4. Нужные разделы назначаются бригадам; опрессовка — отдельной строкой той же бригады.
5. Бригадир вносит время по объекту в MAX или на сайте; начисление считается от СМР
   раздела и доли выполненного.

## Открытые вопросы заказчику

1. Отделять испытания у любого стального газопровода или только у врезки (тип 3).
2. Кто и как ведёт разделы «земля» и «полиэтилен» (тип 4), какими бригадами.
3. Обновлённый фактический отчёт с разделом опрессовки: как называется строка и столбцы.
4. В простой смете (тип 1) внутри раздела стали бывают отдельные строки испытаний. В звонке
   СМР считали «итого по разделу минус материалы», не вычитая их. Выделять ли такие строки
   отдельной строкой отчёта? Пока они входят в СМР стали, мастер показывает их пометкой.
