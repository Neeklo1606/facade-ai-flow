Основание: 01_SPEC, раздел 4. Результат L0: audit/ROUTES.md (все способы навигации по ролям).

```text
Следуй docs/launch/00_SYSTEM.md. Выполни шаг L2.

ADR-048 «Одна модель навигации телефона» до кода: вкладки и экран «Ещё» вместо выдвижного меню,
стек экранов внутри вкладки, история вкладок, повторное касание, системный «назад».
Явно: ADR-048 заменяет ADR-046 для ширины до 767; доступность ADR-046 (удержание фокуса,
Escape, возврат фокуса, строки 48) переносится в «Ещё» и шторки; компьютер и планшет не меняются.
Правки Lovable 22.10 (текст телефона 16/24, компьютер html 87,5%) сохраняются.

1. ВКЛАДКИ
   - Набор вкладок по 01_SPEC 4.3 в одном месте (src/lib/navigation.ts), тесты на каждую роль.
   - Нижняя панель как ADR-045 4.3: плоская 56 + safe-area, иконка 24, подпись 11,
     активный цветом и точкой, бейдж-счётчик (как во ВК) у «Проверка» и «Входящие».
   - Голосовая кнопка ГАЙКИ 56 строго по центру при любом наборе (тест на координату центра).
   - Бригадир /gas: бот на весь экран, без панели (01_SPEC 4.3).

2. ЭКРАН «ЕЩЁ»
   - Маршрут-вкладка, не шторка. Вверху карточка роли: аватар 48, имя, роль, «Сменить роль»
     (шторка ролей). Ниже группы однострочных строк 52 с иконкой 20 (01_SPEC 4.1).
   - Набор строк по роли из того, что было в выдвижном меню и в шторке «Ещё». Ни один раздел
     не теряется: сверь с audit/ROUTES.md, тест что каждый раздел роли достижим за 2 касания.
   - Последняя строка докручивается выше нижней панели.

3. ВЫДВИЖНОЕ МЕНЮ ТЕЛЕФОНА
   - Кнопка меню из шапки телефона убирается, Dialog с SidebarInner на телефоне не монтируется.
     Код SidebarInner остаётся для компьютера.
   - e2e/mobile-navigation.spec.ts (из Lovable) переписать под новую модель: те же проверки
     доступности на экране «Ещё» и шторке ролей. Не удалять файл, заменить сценарий и написать
     в ADR-048, почему.

4. СТЕК И ИСТОРИЯ
   - Корневые экраны вкладок: крупный заголовок, уходящий в шапку (уже есть по ADR-045).
   - Вложенные экраны: шапка «‹ Назад» и название. Признак вложенности в описании маршрута.
   - Своя история у каждой вкладки: при переходе на другую вкладку запоминаются адрес
     и прокрутка, при возврате восстанавливаются (sessionStorage в try/catch).
   - Повторное касание активной вкладки: прокрутка наверх плавно (reduced-motion мгновенно);
     если уже наверху, переход к корню вкладки.
   - Шторки и вложенные экраны закрываются системным «назад». Горизонтальный жест у левого края
     не перехватывать.
   - Переход вглубь сдвигом 250 мс через View Transitions API, где поддерживается; без поддержки
     и при reduced-motion без сдвига.

5. ШАПКА ТЕЛЕФОНА
   - 52 + safe-area: «Назад» на вложенных, заголовок после прокрутки, справа поиск (если экран
     его поддерживает) и аватар роли 32. Бургера нет. Период /gas переезжает под крупный заголовок
     строкой мета.
   - /gas старт на телефоне получает заголовок экрана, как остальные.

6. МЕЛКОЕ ИЗ АУДИТА
   - Подсказка «Как работать с экраном» по умолчанию свёрнута строкой 44 после первого посещения
     и никогда не обрезает текст посреди строки: раскрытая показывает все шаги или кнопку
     «Инструкция». Исправить now-05 и now-07.
   - Бот бригадира: одна шапка чата вместо трёх (шапка приложения на этом экране это шапка чата;
     плашка «Так выглядит бот» становится строкой мета в ней). Лента начинается сверху, без пустоты.
   - Отклик касания без задержки: touch-action manipulation на интерактивных элементах.

Проверка: bun run ci; ui-metrics и ui-taps на 390 (одна нижняя панель, ноль выдвижного меню,
шапка до контента не больше 120); новый e2e e2e/tabs.spec.ts: каждая роль, переходы, повторное
касание, возврат на вкладку с прокруткой, «назад» закрывает шторку; e2e существующие зелёные.
Снимки: «Ещё» каждой роли /gas и ГАЙКИ, бот бригадира, /gas старт, вложенный экран, 390,
обе темы. Запусти bun run dev --host и дай адрес в локальной сети.

ОСТАНОВКА 1. Владелец открывает на своём телефоне. Покажи: снимки до и после
(now-02, now-04, now-05 против новых), экран «Ещё» двух ролей, цифры ui-metrics и ui-taps.
Жди «ок»: дальше эта модель идёт на все экраны и сайт.
```
