# L4. Голос в учёте выработки и показ ГАЙКИ. Класс T2

Основание: 01_SPEC 8 и 7.3, ADR-040 (голос), ADR-038 (канон ГАЙКИ).

```text
Следуй docs/launch/00_SYSTEM.md. Выполни шаг L4.

ADR-049 «Голосовой ввод времени в боте бригадира (демо)» до кода: разбор правилами в domain,
без модели; место для модели через существующий порт ModelGateway позже; что видит бригадир;
пометки демо; бюджет касаний.

1. DOMAIN
   - src/domain/gas-ops/parse-time-message.ts: parseTimeMessage(text, allowedObjects, today)
     → { objectId | null, day | null, start | null, end | null, breakMin | null, quotes }.
     У каждого найденного значения фраза-источник (quote). Неизвестное остаётся null.
   - Числительные словами («восемь», «половина шестого», «без пятнадцати девять»), время через
     двоеточие, точку и без разделителя, «с ... до ...», «перерыв час», «без перерыва», «обед 30».
   - Нечёткое совпадение объекта только среди разрешённых бригаде (правило из ADR-044).
     Два похожих объекта: null и причина «уточните объект».
   - tests/domain/parse-time-message.test.ts: не меньше 20 фраз из 01_SPEC 8 плюс крайние случаи.

2. БОТ
   - Под «Выберите объект» кнопка «Сказать голосом» 48. Запись компонентом голоса ГАЙКИ.
     После «Готово» подготовленная фраза с пометкой «Демо: фраза подготовлена заранее»,
     поле «или напишите текстом». Любой набранный текст разбирается тем же правилом.
   - Этапы текстом (ADR-045 4.18), затем сводка шага 7. Пустые значения спрашиваются кнопками
     следующего шага, а не угадываются.
   - Пересечение с записями бригады проверяется до сводки, как в кнопочном пути.
   - В показе gas-week на шаге 1 полоса показа предлагает оба пути, засчитывается любой.

3. ГАЙКА
   - Канон ADR-038 проходит в новой оболочке L2 без регрессий касаний.
   - Финал ГАЙКИ ведёт на «Разобрать мои данные» (/razbor, отметка demo-final) и «Вернуться на сайт».
   - Экран «Запись»: если микрофона нет, путь «Показать без микрофона» (ADR-040) работает на 390.

Проверка: bun run ci; тесты domain; e2e голосового пути бота на 390 (запись через fake media
stream и путь текстом), бюджет 3 касания; канон ГАЙКИ e2e на 390; снимки этапов разбора.
Отчёт. Без остановки.
```
