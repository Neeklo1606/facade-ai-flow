## 4. Риски

1. **Данные заказчика в публичном репозитории.** Репозиторий PUBLIC. Перенос в серверный модуль
   закрывает сайт, но не GitHub. Нужна закрытая история или приватный репозиторий (вопрос 1).
2. **Серверная отдача в Lovable.** Опубликованный адрес уже рендерит страницы на сервере
   (HTML приходит готовым), значит серверные функции на хостинге есть. Превью редактора Lovable
   запускает dev-сервер Vite с тем же SSR. Риск в другом: /gas сейчас целиком строит состояние
   в браузере из импортированного набора. Личный контур потребует загрузить набор с сервера
   до первого рендера. Если это сломает превью, ОСТАНОВКА с вариантами по L1 п. 4.
3. **Lighthouse на телефоне.** Сейчас корень 76, LCP 2,9 с на опубликованном адресе. Лендинг
   отдельным куском до 90 КБ и шрифт с preload должны дать 90+, подтвердится только после Publish.
4. **Превью ссылок** проверяется краулерами только на опубликованном адресе (L10).
5. **История вкладок** без перехвата жеста у края: проверка только на реальном iPhone (ОСТАНОВКА 1).
