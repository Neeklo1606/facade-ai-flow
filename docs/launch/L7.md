# L7. Планшет, компьютер, кабинет компании. Класс T2

Основание: ADR-045 (V7, V8), 01_SPEC 3 и 5. Правка Lovable: компьютер html 87,5%.

```text
Следуй docs/launch/00_SYSTEM.md. Выполни шаг L7.

1. ПРИЛОЖЕНИЕ
   - Проверь, что модель L2 не задела планшет и компьютер: рельс 72 на 768-1023, сайдбар 248
     со сворачиванием от 1024, деталь справа 420, клавиши J, K, Enter, Esc.
   - Компьютер при html 87,5%: ничего мельче 12 px в пересчёте, касание мышью от 32,
     таблицы читаются на 1280. Если что-то стало мельче, подними только этот токен.
   - /gas старт на компьютере без вида лендинга (L3), отчёт «Во весь экран» работает.

2. САЙТ
   - Лендинг на 768, 1024, 1280, 1440, 1920: сетка, ширина текста до 640, контент до 1200,
     живые фрагменты справа от текста на 1024+, на планшете под текстом.
   - /demo на компьютере: две карточки рядом.

3. КАБИНЕТ /office
   - Сайдбар, таблицы ADR-045 4.16, формы в панели справа. Раздел «Подключения» показывает
     статус приёма заявок (none, telegram, webhook) без значений ключей и статус личного контура.
   - На телефоне /office открывается списком строк и честной строкой «Кабинет удобнее на компьютере».

Проверка: bun run ci; ui-metrics на 768, 1024, 1280, 1440, 1920 в обеих темах; ноль переполнения;
снимки в docs/launch/after/desktop/. Отчёт. Без остановки.
```
