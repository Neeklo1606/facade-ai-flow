# L5. Лендинг. Класс T2

Основание: 01_SPEC 5 (дизайн сайта) и 9 (структура и тексты). Каркас сайта из L1.

```text
Следуй docs/launch/00_SYSTEM.md. Выполни шаг L5.

ADR-050 «Лендинг ГАЙКИ» до кода: структура, живые фрагменты вместо картинок, шкала сайта,
бюджет скорости, что берём из REFERENCES.md и почему.

1. ТЕКСТЫ
   Перенеси тексты 01_SPEC 9 в src/lib/site/copy.ts дословно. Сокращать можно, добавлять
   обещания и цифры нельзя. Если формулировка не влезает в вёрстку, сократи и перечисли
   правки в отчёте.

2. СЕКЦИИ 1-12 (01_SPEC 9)
   - Первый экран целиком в 390 x 664: метка, H1, подзаголовок, две кнопки, строка
     «Без регистрации. С телефона. 3 минуты.». На компьютере справа живая последовательность.
   - Живые фрагменты собираются из компонентов приложения (пузырь бота, ListRow проверки,
     строка отчёта) с данными публичного набора. Анимация один раз при появлении
     (IntersectionObserver), reduced-motion без анимации. Никаких картинок телефона.
   - Шкала, поля, секции, ширина по 01_SPEC 5. Одна тёмная секция «Как это работает».
   - Блок видео показывается, только если задан VITE_VIDEO_URL: постер, кнопка воспроизведения,
     видео грузится по нажатию, а не сразу.
   - Блок «Как начать»: цены из config, без значения строка цены не выводится вовсе.
   - Вопросы: аккордеон на details/summary, доступен с клавиатуры.
   - Форма заявки: поля 01_SPEC 9.11, пока отправка через честный переход в Telegram
     (адаптер none), сам порт и адаптеры делаются в L6. Поле телефона inputmode tel и маска +7.

3. ПОВЕДЕНИЕ
   - Шапка сайта 56, «Открыть демо» капсулой справа. Липкая кнопка «Открыть демо» внизу
     на телефоне после первого экрана, прячется, когда форма в зоне видимости.
   - Все кнопки демо ведут на /demo, кнопки разбора на /razbor с отметкой источника.
   - Тёмная и светлая тема по системе, переключателя на сайте нет.

4. СКОРОСТЬ
   - Лендинг отдельным куском сборки, без кода приложения в первом куске. Шрифт Inter
     с preload и font-display swap. Фрагменты ниже первого экрана грузятся лениво.
   - Бюджет: первый кусок лендинга не больше 90 КБ gzip (запиши в bundle-budget.json).

Проверка: bun run ci; Lighthouse mobile на собранном сайте (Performance от 90, CLS до 0,05,
Accessibility 100; LCP подтверждается на опубликованном адресе в L10); снимки лендинга
целиком на 375, 390, 430, 768, 1280, 1440, 1920 в обеих темах в docs/launch/after/site/;
проверка текстов скриптом (длинные тире, капс, запрещённые слова). Открой каждый снимок
и сравни с правилами 01_SPEC 5. Отчёт. Без остановки.
```
