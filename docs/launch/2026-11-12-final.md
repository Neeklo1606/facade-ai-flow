### Исправлено при финальной проверке

1. Прыжок страницы наверх сразу после загрузки: касание по ссылке приходилось мимо (раздел 4).
2. Адрес сайта в образе. `VITE_PUBLIC_URL` подставляется при сборке, а образ его не получал:
   canonical, sitemap, og:url и JSON-LD вели бы на адрес Lovable. Теперь compose передаёт
   `https://$DOMAIN`, вместе с ним `CONTACT_TG`, `METRIKA_ID` и коды подтверждения поисковиков.
3. Секреты в слое сборки. `.dockerignore` не исключал `deploy/.env`: файл попадал в сборочный
   слой, из которого собирается `migrate`. Теперь `.env`, `.env.*` и `deploy/.env` исключены.
4. Новый сквозной тест `e2e/gas-customer-flow.spec.ts`: весь путь показа заказчику на одной
   вкладке со сверкой значений в ячейках выгруженного Excel.

## 2. Инструкция

### Посмотреть локально

```bash
bun install --frozen-lockfile
bun run dev            # http://localhost:4620
```

Сайт: `/`, `/dlya-kogo`, `/kak-rabotaet`, `/stati`. Приложение: `/gas`, роль выбирается
из списка ролей (демо-вход без пароля, до шага D отчёта). Роль меняет вкладки и стартовый экран.

### Пройти сценарии в демо

| Роль         | Где               | Что сделать                                                                    |
| ------------ | ----------------- | ------------------------------------------------------------------------------ |
| Бригадир     | `/gas/brigade`    | внести часы бригады за день, отправить                                         |
| Менеджер     | `/gas/moderation` | на телефоне нажать «Принять N без замечаний»; открыть запись и увидеть её путь |
| Менеджер     | `/gas/tabel`      | выделить ячейки, увидеть итог, скопировать                                     |
| Руководитель | `/gas/week`       | неделя по объектам и бригадам, вопрос агенту про неделю                        |
| Заказчик     | ссылка `/gas?c=…` | отчёт недели по личной ссылке (сейчас на тестовых данных)                      |

### Выложить на сервер

Полностью в `docs/runbook/docker.md`. Коротко:

```bash
cp deploy/.env.example deploy/.env      # DOMAIN, POSTGRES_PASSWORD, SESSION_SECRET, CLIENT_LINK_KEY
docker compose --env-file deploy/.env up -d db
docker compose --env-file deploy/.env --profile tools run --rm migrate   # T3: только с «да» владельца
docker compose --env-file deploy/.env up -d --build app caddy
```

`GAIKA_MODE=production` поднимает демо-контур без базы: его можно выложить сразу, данные живут
во вкладке браузера. `GAIKA_MODE=server` нужен для живых данных и требует шагов D и E плана.
`SEO_INDEX=on` открывает сайт поисковикам.

## 3. Сценарий показа заказчику: учёт выработки бригад

Этот путь целиком закреплён тестом `e2e/gas-customer-flow.spec.ts` на 1440 и 390, цифры
ниже взяты из его прогона. Перед встречей «Сбросить демо» (компьютер: меню слева внизу,
телефон: «Ещё»). Файлы для показа: бригады, сотрудники, график недели и смета в Excel.

| №   | Роль          | Где               | Что делать                                                                                         | Что видит заказчик                                                                               |
| --- | ------------- | ----------------- | -------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| 1   | Администратор | `/gas/directory`  | «Бригады из Excel», затем «Сотрудники из Excel», «Всё верно, применить»                            | отчёт «добавится, обновится, пропущено» с причинами по строкам; повтор файла не задваивает людей |
| 2   | Менеджер      | `/gas/objects`    | «Добавить объект»: адрес, номер, вид работ                                                         | объект в списке; повтор номера отклоняется                                                       |
| 3   | Менеджер      | `/gas/objects`    | «Загрузить график недели»: объект, номер, бригада, дата                                            | лист и строки выбираются, «Все строки прочитаны»; бот бригады сразу предлагает этот объект       |
| 4   | Менеджер      | `/gas/estimates`  | «Загрузить смету», при желании «Изменить» колонки, «Всё верно, применить»                          | колонки найдены сами, у каждой пример из файла; «Разделы сходятся с итогом без НДС, строка 519»  |
| 5   | Менеджер      | `/gas/estimates`  | «Выбрать объект», «Замечания проверены», «Подтвердить смету»                                       | стоимость работ по правилу «Всего без НДС минус материалы» со строками файла                     |
| 6   | Менеджер      | `/gas/estimates`  | «Настроить»: какие строки сметы плюсом, какие минусом, «Сохранить редакцию», «Подтвердить правило» | живой пример на этой смете, итог меняется сразу; история редакций, отмена 6 секунд               |
| 7   | Бригадир      | `/gas/foreman`    | «Внести время» → объект → «Сегодня» → фраза «с 8 до 17» → «Верно» → перерыв → «Отправить»          | 480 мин = 8,00 ч, номер записи; бригадир не видит денег                                          |
| 8   | Менеджер      | `/gas/moderation` | открыть запись, «Принять»                                                                          | доля сметы, источник «смета объекта, версия 1», сколько на час; путь записи                      |
| 9   | Руководитель  | `/gas/tabel`      | «Выгрузить Excel» (компьютер: меню «Выгрузить», «Excel утверждённый»)                              | файл `Выработка_бригад_<период>.xlsx`: листы «Отчёт», «Записи», «Как считалось»                  |
| 10  | Руководитель  | `/gas/week`       | «Сверка с отчётом заказчика»: загрузить файл                                                       | «Расхождений нет: N пар объект · день совпали до рубля и до сотой часа»                          |

Цифры прогона: смета 100 000,23 ₽ без НДС минус материалы; с технадзором 105 000,23 ₽;
запись 08:00–17:00, перерыв 60 мин, 480 мин. В Excel: 105 000 ₽ (стоимость в целых рублях,
округление в конце), 8,00 ч, 13 125 ₽/ч. Если на объекте несколько записей, стоимость делится
между ними по минутам, сумма частей равна стоимости объекта ровно.

**Что говорить вслух один раз:** бот MAX и облачные таблицы не подключены. Бот на экране
работает так же, как будет в MAX. Данные показа живут в этом браузере.

### Найдено и исправлено при тестировании

1. **Прыжок страницы наверх после загрузки.** Роутер при первой отрисовке после гидратации
   прокручивал окно в начало, даже если человек уже пролистал страницу. Касание по плитке
   на `/demo` или по «Ещё» приходилось мимо ссылки. На тестах это было 1–2 падения из 50,
   и на ветке, и на `feature/gas-ux-v5`. Исправлено в `src/lib/scroll-restore.ts`
   с юнит-тестом.
2. **Адрес сайта в Docker-образе** (canonical, sitemap, og:url вели на Lovable).
3. **Секреты в слое сборки** (`deploy/.env` не был исключён).
