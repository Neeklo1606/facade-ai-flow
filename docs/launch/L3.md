# L3. Учёт выработки: финальный проход экранов и показа. Класс T2

Основание: 01_SPEC 7.2, ADR-044, ADR-045 раздел 5.1-5.11. Модель навигации из L2.

```text
Следуй docs/launch/00_SYSTEM.md. Выполни шаг L3.

Цель: показ учёта выработки на публичном наборе проходит с телефона за 3 минуты, каждый экран
выглядит законченным, и после финала человек знает, что делать дальше.

1. СТАРТ /gas
   - Телефон: крупный заголовок «Учёт выработки бригад», одна строка о системе, главная кнопка
     «Начать показ: 3 минуты» в первом экране (на 390 не ниже 400 pt от верха), «Войти как ...»
     тихой кнопкой, схема из четырёх шагов строками ListRow, блок «Что входит» свёрнутым.
     Градиент только узкой полосой в первом экране или нет совсем: решение по снимку.
   - Компьютер: убрать вид лендинга внутри приложения (now-21). Рабочий старт: заголовок,
     строка, кнопка показа, схема шагов в ряд, без огромного героя.

2. ПОКАЗ gas-week
   - Полоса показа сверху (ADR-045 4.4) с кнопкой «Выйти из показа» → /demo.
   - Переход между ролями внутри показа без лишних экранов: тост «Вы смотрите как ...».
   - Финал по 01_SPEC 7.2: «Что создано за показ», «Разобрать мои данные» (главная) → /razbor
     с отметкой demo-final, «Пройти заново», «Посмотреть голос с объекта», «Вернуться на сайт».
     Пока /razbor заготовка из L1, кнопка всё равно ведёт туда.

3. ЭКРАНЫ (по каждому снимок до и после на 390 и 1440)
   Бот, проверка, карточка записи, журнал, отчёт, бригады, объекты, сметы, сотрудники,
   настройка, вопросы, инструкция, сводка, финал. Для каждого проверь по ADR-045 разделу 6
   и новому правилу: на экране одно главное действие, ничего не обрезано, нет пустот больше
   экрана, подписи кнопок говорят, что будет. Найденное в L0 audit/J1.md закрыть или объяснить.
   Отчёт /gas на телефоне: итог недели одной карточкой, одна строка управления, дерево списком;
   ничего крупнее 32 кроме одного главного числа.

4. ТЕКСТЫ /gas
   Один словарь статусов и действий (ADR-045 4.21). Проверка скриптом: ноль длинных тире,
   капса, эмодзи и слов «эффективно», «удобно», «легко» в src/components/gas-ops и src/routes/gas.

Проверка: bun run ci; e2e gas-week на 390 и 1440 на публичном наборе до финала и переход
на /razbor; ui-taps (показ /gas не больше 13 касаний, бот 6, подтверждение 2);
gas-walk на 375, 390, 430, 768, 1440; пары снимков в docs/launch/after/gas/.
Отчёт. Без остановки.
```
