# Аудит J1: холодный ЛПР с телефона

Версия 1.0 от 22.10.2026, шаг L0. База ff93d98, демо-сборка `bun run build`, локальный сервер.
Телефон 390 x 844, касания, `ru-RU`. Сценарий прохода `docs/launch/audit/j1-walk.ts`,
снимки `j1-01.png` ... `j1-21.png` в этой папке.

Путь J1 по 01_SPEC 2: превью ссылки → лендинг → «Открыть демо» → показ учёта выработки →
финал → «Разобрать мои данные» → заявка. Сейчас путь обрывается на втором шаге: лендинга нет,
со входа ГАЙКИ нет дороги к учёту выработки, после финала заявку оставить негде.

## Пять главных трений

1. Лендинга нет: корень продаёт голос ГАЙКИ, учёт выработки по ссылке не найти.
2. Заявку оставить негде, финал ведёт только на «Пройти заново».
3. В публичном /gas видны название, суммы и населённые пункты газового заказчика.
4. Экраны ГАЙКИ без роли и весь /gas без пути назад к сайту и ко второму сценарию.
5. На телефоне три навигации сразу, а в показе тосты закрывают главные кнопки.
