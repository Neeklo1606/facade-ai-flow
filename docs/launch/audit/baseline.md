# Базовая линия L0

Версия 1.0 от 22.10.2026, шаг L0. База: origin/main ff93d98 (новее ff93d98 коммитов нет).
Машина: macOS, bun 1.3, PostgreSQL 16.13 локально.

## 1. Конвейер `bun run ci`

`bun run ci` на ff93d98 падает. Две причины, обе пришли с правками из Lovable после V11:

| Шаг | Код | Время | Что |
|---|---|---|---|
| Типы | 0 | 130 с | |
| Линтер | 1 | 43 с | prettier в `e2e/mobile-navigation.spec.ts` (2 ошибки, файл из коммита Lovable 2449ad3) |
| Тесты domain, согласованность, негативные | 0 | 8 с | 974 прошло, 0 упало, 49 файлов |
| Фикстуры против схемы | 0 | 0,4 с | |
| Ссылки в документах | 0 | 0,2 с | |
| Шкала размеров | 0 | 0,5 с | |
| PostgreSQL: миграции, паритет | 0 | 214 с | локально нужен `?sslmode=disable` в `CHECK_DATABASE_URL` |
| Сборка рабочего контура | 0 | 36 с | |
| Размер бандла: рабочий контур | 0 | 1 с | 682,8 КБ при пороге 690; самый большой кусок 167,6 при 169 |
| Сборка демонстрации | 0 | 37 с | |
| Размер бандла: демонстрация | 0 | 1 с | 737,8 КБ при пороге 745; самый большой кусок 168,6 при 169 |
| Сквозные тесты | 1 | 1092 с | 372 прошло, 18 пропущено, 1 упал |
| Lighthouse | 0 | отдельно | см. раздел 3 |

Упавший сквозной тест: `e2e/gas-bot.spec.ts:49` «бот бригадира 1440, полный проход за 6 касаний»,
4 кнопки бота ниже 48 px. Причина по всей видимости в правке Lovable «компьютер компактнее
на 12 %» (`html` 87,5 % от 1024 px): кнопка 48 стала 42. На CI GitHub коммит 647bcea
до правок Lovable прошёл (371 прошло).

Прогон шагов после линтера сделан той же программой `scripts/ci.ts` без шага «Линтер»,
чтобы получить цифры остальных шагов. Общее время прогона 25 мин 22 с.

Порог бандла почти выбран: в демо 7,2 КБ запаса, в самом большом куске 0,4 КБ. Публичный сайт
(L1, L5, L6) должен грузиться отдельными кусками, иначе порог 169 будет пробит.

и правки Lovable 22.10 (`html` 87,5 %, выдвижное меню). Поправка от 23.10: в первой версии
этого файла было написано, что Publish не нажат, потому что `/design-system` отвечает 404.
Это неверно: витрина намеренно удалена из production (`src/server.ts`, `isRemovedInProduction`).
Для лендинга порог 01_SPEC 14 (LCP до 2,5 с) сейчас не выполняется даже у старого корня.

## 4. Как повторить

```
bun run ci                                     # с CHECK_DATABASE_URL=...?sslmode=disable
PORT=4640 node .output/server/index.mjs &
UI_METRICS_BASE=http://localhost:4640 UI_METRICS_OUT=l0 bun scripts/ui-metrics.ts
UI_METRICS_BASE=http://localhost:4640 UI_METRICS_OUT=l0 bun scripts/ui-taps.ts
LH_BASE=https://facade-ai-flow.lovable.app bun run lighthouse
J1_BASE=http://localhost:4640 bun docs/launch/audit/j1-walk.ts
```
