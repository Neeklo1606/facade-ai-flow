## Что нужно серверу от приложения (инфраструктура газовой компании)

- Сборка рабочего контура: `VITE_DATA_SOURCE=server`, `NITRO_PRESET=node-server`,
  `bun run build:server`; кабинет заказчика: `VITE_CABINET_ONLY` с тем же сервером.
- Переменные сервера: `DATABASE_URL`, `CLIENT_LINK_KEY`, `MAX_BOT_TOKEN`,
  `MAX_WEBHOOK_SECRET`, `GAS_SHEETS_SA_JSON`, `GAS_SHEET_ID` (список целиком в
  `docs/BACKEND_HANDOFF.md`).
- По расписанию: `remindersAt` каждые 5–10 минут (вопросы сразу, 18:00, 19:00) через
  `OutboundMessenger`; `pushWeekSheet` после изменений, не чаще раза в минуту, адаптер
  `googleSheetSyncFromEnv(process.env)`.
- Миграции `db/` на рабочей базе — только с вашего «ок».
