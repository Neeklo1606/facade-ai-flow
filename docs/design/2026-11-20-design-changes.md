# Правки дизайна по обратной связи 20.11.2026 и разбору ПТО Онлайн

## 1. Разбор ПТО Онлайн: как расположены элементы

Внутрь приложения без оплаты не пускает: при нулевом балансе любой раздел ведёт на «Тарифы».
Ниже — то, что видно в оболочке, на тарифах и в справочном центре (около 100 статей с описанием
экранов и кнопок).

### Оболочка

| Место | Что там |
| --- | --- |
| Верхняя полоса слева | логотип «ПТО онлайн» |
| Верхняя полоса, центр | разделы портала: Объекты, ЭДО, Сотрудники, Менеджер, Аналитика |
| Верхняя полоса справа | поиск, колокольчик уведомлений со счётчиком, «?» справка, имя и аватар |
| Правый нижний угол | круглая кнопка AI-помощника; он знает открытый объект и документ |
| Внутри объекта слева | меню разделов объекта; сворачивается кнопкой над списком, состояние запоминается |

Иерархия жёсткая и одна на весь продукт: портал → объект → шифр (раздел работ) → документ.

### Список и карточка объекта

- «Объекты» — стартовый экран: карточки строек, поиск по названию, «Создать объект», архив
  иконкой рядом с заголовком.
- Создание: название и адрес, тип журнала, «Сохранить» — сразу открывается карточка объекта.
- Первый пункт левого меню — «Общая информация»: реквизиты стройки, которые потом
  подставляются в документы. Внизу карточки — быстрые переходы к шифрам и правам доступа.

### Документы

- Таблица со статусами, авторами и датами; слева фильтр по типам.
- Двойной клик или правая кнопка «Изменить» — открыть. Отметить галочками и «Удалить» над
  таблицей; окно объясняет, что уйдёт в корзину.
- «Создать» → тип и шаблон → форма с автоподстановкой → «Сохранить».
- Статусы: В работе → На подпись → Исправление → Подписан → Сдан. При переводе на подпись
  автопроверка; ошибки видны плашкой в документе и отметкой в списке, но не блокируют.

### Сметы — самое полезное для нас

- Плашка: крупно итог сметы, строкой ниже сумма позиций, с пояснением, почему они расходятся.
- Кнопка **«Смотреть смету»** делит экран пополам: слева позиции в программе, справа файл как
  в Excel. Клик по позиции прокручивает файл к её строке и подсвечивает её. Обратно — так же.

### Аналитика

- «Портфель объектов»: все объекты одной таблицей, где отставание, где не платят.
- «Сводка по объекту»: сроки, финансы, объёмы, документация.
- **Суммы подчёркнуты пунктиром:** нажал — поверх открывается расшифровка, из чего сложилась
  цифра, итог совпадает с карточкой.

### Обучение

- Два тура при первом входе: по порталу и по объекту, показываются один раз.
- «Демонстрационный объект»: заполненный, на нём можно всё, включая удаление.
- «Что нового» в справочном центре.

## 2. Что берём и как адаптируем под ГАЙКУ

| Приём ПТО Онлайн | У нас | Правка |
| --- | --- | --- |
| «Смотреть смету»: позиции и файл рядом с подсветкой строки | в карточке сметы номера строк есть, файла рядом нет | **D1.** Кнопка «Сверить с файлом»: слева разделы и шапка, справа лист файла; клик по значению подсвечивает строку. На телефоне две вкладки «Разбор» и «Файл» |
| Суммы с пунктиром и расшифровкой | у суммы есть источник строкой | **D2.** Сумма записи, начислено и остаток раздела раскрываются по нажатию: список шагов доли и записей, итог совпадает |
| Карточка объекта — центр, всё из неё | объект в шторке справочника | **D3.** Отдельная страница объекта: шапка (адрес, номер, смета, файл), вкладки «Разделы», «Записи», «История». Из списка объектов и из сметы — сюда |
| Иерархия портал → объект → шифр → документ | смета, объект, раздел, запись разбросаны по экранам | **D4.** Одна линия везде: Объект → Раздел → Запись времени. Хлебные крошки так и пишут |
| Создать объект → сразу карточка | после «Создать объект» остаёмся на смете | **D5.** После создания открывается страница объекта с подсказкой «Назначьте разделы бригадам» |
| Демо-объект | демо есть, но не названо | **D6.** «Демо-объект» на стартовом экране и кнопка «Сбросить демо» |
| Статусы с понятным путём | у записи есть путь «Внесено → Проверено → Подтверждено → В отчёте» | оставить, вынести на карточку очереди |
| Таблица с галочками и действием над таблицей | «Проверка» карточками | **D7.** На компьютере режим «Таблица» в «Проверке»: галочки, колонки как в табеле, действие над таблицей. Карточки остаются на телефоне |
| Сворачиваемое меню с памятью | есть «Свернуть» | оставить |

### Что не берём

- Блокировку всего приложения при неоплате: просмотр своих данных остаётся всегда.
- Иконку «ассистента» поверх контента без подписи: у нас кнопка с подписью на компьютере.
- Цифры без источника на лендинге.

## 4. Лендинг: палитра ПТО Онлайн

Решение владельца: лендинг перекрашивается в палитру pto-app.ru. Сервис внутри остаётся на
своих токенах до отдельного решения (правило проекта про оранжевый акцент относится к сервису).

| Токен | Значение | Где |
| --- | --- | --- |
| primary | #3448F0 | кнопки, ссылки, акцент |
| primary-strong | #4B2EF5 | главная кнопка заявки |
| primary-soft | #E8EBFF | плашки, выделение |
| primary-tint | rgba(52, 72, 240, 0.08) | фоны карточек |
| ink | #2A2F5B | заголовки и текст |
| ink-strong | #0D1B2A | крупные цифры |
| muted | #5A6078 | второстепенный текст |
| surface | #FFFFFF | карточки |
| background | #FAFBFD | фон страницы |
| background-2 | #EEF3F9 | чередование секций |
| hero | тёмно-синий градиент #0D1B2A → #1B2150 | первый экран |
| font | Manrope, запасной Inter | весь лендинг, вес до 700 в заголовках |

Радиусы: кнопки 10–16 px, карточки 16–24 px.

### Правки лендинга

| # | Что | Нужны данные владельца |
| --- | --- | --- |
| L1 | Палитра и шрифт выше | нет |
| L2 | Короткая форма в первом экране: имя и телефон, рядом «Посмотреть демо» | нет |
| L3 | Демо-объект и «Сбросить демо» (D6) | нет |
| L4 | Справочный центр по разделам вместо одной инструкции, «Что нового» по датам | нет |
| L5 | Реквизиты компании в подвале | да: юрлицо, ИНН, адрес, телефон |
| L6 | Цифра результата в первом экране | да: замер из пилота |
| L7 | Страница цен | да: цена |
| L8 | Видео 2–3 минуты | да: запись или согласие на монтаж из демо |
| L9 | Таблица «чем отличаемся» от Excel и чата | нет |
