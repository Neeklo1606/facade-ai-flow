# Табель на телефоне: отчёт

15.11.2026 · ветка `feature/tabel-mobile-grid` · решение `docs/adr/ADR-071-tabel-phone-grid.md`.
Основание: снимок владельца с iPhone, «с телефона неудобно пользоваться таблицей,
сделай наподобие Google Sheets».

## Что было и что стало

| Было | Стало |
| --- | --- |
| Первый столбец 320 px из 358, чисел не видно | 150 px, название в две строки, сразу видны сумма и часы дня |
| Панель над таблицей в 5 строк, таблица с середины экрана | Одна строка: «Списком», период, «Вид и фильтры», «Во весь экран», «Выгрузить» |
| Таблица на полэкрана | До нижнего меню. «Во весь экран» закрывает меню и шапку |
| Записи ячейки открывались двойным кликом, на телефоне его нет | Касание выделяет, второе касание по той же ячейке открывает записи |
| Итог выделенного внизу не помещался | Одна строка под таблицей: «Сумма», «Среднее», «Ячеек» |
| Итог столбца складывал бригаду, бригадира и объекты: часы втрое больше | Считаются только объекты, пометка «без итогов групп». Исправлено и на компьютере |
| Выбор «таблицей» терялся при каждом открытии | Запоминается на телефоне |

Как в Google Таблицах: касание по заголовку дня выделяет столбец, по названию строки выделяет
строку, итог внизу. Первый столбец и шапка закреплены при прокрутке в обе стороны.

## Проверки

- `bun run ci` с локальной PostgreSQL: все шаги пройдены.
- Юнит-тесты: 1455 прошли, 0 упали (новый тест: итог без двойного счёта).
- e2e: 598 прошли, 18 пропущены, 0 упали (новый сценарий на 390 с касаниями).
- Lighthouse и первый экран бригадира на 4G (LCP 2,0 с при пороге 2,5 с) пройдены.
- Прокрутка вбок страницы 0 px, ошибок в консоли 0.

## Что осталось

- Итог столбца часов 64,81 при «Итого» 64,83: в ячейках часы округлены до сотых,
  сумма округлённых расходится на 0,02. Так же считают Google Таблицы.
- Кнопка помощника справа внизу перекрывает угол таблицы. Она общая для всех экранов,
  не трогал.
- Вид «По людям» в демо-данных пуст: бригадиры не отмечают людей в записи.
