# Компактное рабочее пространство — 17.11.2026

Цель: подготовить понятную демонстрацию на существующих данных без изменения расчётов.

1. Проверка: явный период, быстрый выбор недели/всех дат, отдельные дата, интервал, часы и сумма; раскрытие и подтверждение сохраняются.
2. Неделя: компактные показатели факта и дневная разбивка вместо высокого баннера; переходы к проверке и табелю.
3. Табель: плотная сетка, цветовые пометки выделения с сохранением в браузере, независимые от финансовых статусов.
4. Бригады: компактная адаптивная панель, переход к составу и назначению объекта; действия доступны только разрешённым ролям, ошибки сохранения показываются.
5. Проверка: типы, линтер, сборка, доменные тесты, браузерные сценарии на компьютере/телефоне, светлая/тёмная темы. Отдельный отчёт о фактических результатах и границах демо. Коммит и синхронизация main разрешены пользователем, публикация Lovable проверяется отдельно.

Уточнение по мобильному макету после просмотра снимков: период раскрывается отдельной
кнопкой, чтобы фильтры не занимали первый экран целиком; цветовая панель сетки остаётся в
одну строку. Кнопки индивидуальной проверки перенесены перед длинными замечаниями.
