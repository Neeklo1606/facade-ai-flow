# Компактное рабочее пространство ГАЙКИ — 17.11.2026

## Что изменено

- Проверка: дата, интервал, часы и сумма разнесены по отдельным полям одинаковых карточек.
  До принятия сумма подписана «К проверке». Автор, время внесения и источник остаются в детали.
  Даты локализованы; есть быстрые «Неделя отчёта» и «Все даты». На телефоне период раскрывается
  отдельной кнопкой, оставляя больше места записям. Кнопки решения стоят перед длинной детализацией.
- Табель: сетка Arial 13 px, тонкие границы и мягкое выделение групп, мобильные строки 48 px.
  Жёлтые/зелёные/сиреневые пометки выделенного диапазона сохраняются и очищаются в браузере.
  Статусы данных остаются отдельными; числа, расчёт и утверждённый Excel не меняются.
  Панель пометок измеряет свою высоту, чтобы оставлять сетку в границах окна.
- Неделя: компактные показатели факта, точные суммы по дням, переходы к проверке и табелю.
  Убраны высокий декоративный баннер, анимация денег и крупный график. Формулы не менялись.
- Бригады: адаптивная панель вместо шторки на весь монитор, назначение объекта из карточки,
  переход в состав сразу с выбранной бригадой; добавление сотрудника отдельной формой.
  Создание бригад/редактирование доступности скрыто для ролей без соответствующего права.
  Частичная ошибка добавления состава больше не маскируется сообщением полного успеха.
- Исправлена семантика пустого состава новой бригады, найденная проверкой доступности.

- Полный основной браузерный набор: 55/55 pass, Chromium, компьютер и телефон.
  Включает смету → объект → график → бот-симулятор → проверку → XLSX и сверку файла;
  изменение с причиной, уточнение/отклонение, историю, отмену, клавиатуру, выделение/TSV,
  сохранение своих данных, доступ руководителя к сметам и ограничения состава.

- Дополнительная матрица: 375 px dark, 1440 px dark, 320 px light. 18 комбинаций подтверждены в нескольких прогонах после исправлений.

  и лишняя высота сводки на 320 px. Таймаут аудита пометок на 320 px отдельно перепроверен
  без увеличения лимита: сценарий прошёл. Финальные два адресных сценария — 2/2 pass.
- Типы, линтер (0 ошибок, 42 прежних предупреждения Fast Refresh), русские тексты и фикстуры проверены.

## Границы демонстрации

Данные demo и пометки сохраняются в браузере. Реальное подключение MAX/Telegram, транскрипция,
архив исходных файлов и VPS не включались и не изображаются успешными запросами.
Рабочая инструкция: [CUSTOMER_SHOW.md](CUSTOMER_SHOW.md). API/БД/MAX: [BACKEND_HANDOFF.md](BACKEND_HANDOFF.md).
Проект долевого начисления остаётся отдельным прототипом и не меняет утверждённые финансовые правила.

## Выпуск

Пользователь разрешил коммит и push в подключённую ветку main. История не переписывается.
Доступа к интерфейсу Lovable и его кнопке Publish у инструментов этой среды нет.
После синхронизации Git владелец открывает Lovable → Publish → Update, затем проверяет
`/gas/moderation`, `/gas/tabel`, `/gas/week`, `/gas/brigades` и `/gas/demo`.
Техническая сборка и синхронизация не считаются публикацией production.

## Воспроизведение и размер сборки

После `NITRO_PRESET=node-server bun run build`:

```sh
PW_CHROMIUM=/usr/bin/chromium bun run test:e2e --project=desktop --project=mobile e2e/gas-compact-workspace.spec.ts e2e/gas-review-selection.spec.ts e2e/gas-review.spec.ts e2e/tabel.spec.ts e2e/gas-375.spec.ts e2e/gas-customer-flow.spec.ts e2e/gas-demo-workspace.spec.ts
PW_CHROMIUM=/usr/bin/chromium bunx playwright test --config playwright.compact.config.ts
```

В первом командном наборе после добавления отдельного теста администратора будет 57 случаев;
этот тест дополнительно выполнен в матрице на всех трёх экранах.
Сборки demo, server и сборка хостинга без принудительного NITRO_PRESET прошли.
Финально восстановлена node/demo-сборка для локального показа.
Бюджет: demo 1028,9 / 1040 КБ, server 972,2 / 982 КБ gzip; крупнейшие начальные куски
109,4 и 108,3 / 110 КБ. Новых зависимостей нет. Порог общей суммы скорректирован по замеру
с запасом около 1 %, см. ADR-076; исходный запас предыдущего выпуска был почти исчерпан.
