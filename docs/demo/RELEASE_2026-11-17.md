## Публикация

Рабочая конфигурация проекта: GitHub main → синхронизация в Lovable → Publish → Update.
Git push обновляет исходники, но не доказывает публикацию. В текущей сессии нет инструмента
управления подписанным интерфейсом Lovable и нет binding для автоматической публикации.
Публикация выполняется владельцем через Publish → Update после синхронизации main.

До этого шага опубликованный `/gas/demo` отвечал 404: выпуск нельзя обозначать уже
доступным на production. После публикации проверить адрес `/gas/demo`, вход менеджером,
мобильную форму, смету → проверку → табель, скачивание XLSX. В своей вкладке не запускать
старый тур со сбросом, если уже загружены файлы клиента; вход — «Сценарий на ваших данных».
