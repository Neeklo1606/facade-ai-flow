# Capability matrix сайта v2

Этап N0 задания `docs/site/GAIKA_SITE_V2.md`, 11.11.2026, база origin/main 0b30f4c.
Каждое функциональное обещание страниц сайта стоит здесь со статусом и доказательством.
Нет строки: на сайте не пишем. Пути от корня репозитория.

Статусы: **заказчик** (работает у заказчика в рабочем контуре), **пилот** (заказчик смотрит
на своих данных по личной ссылке, рабочей базы нет), **демо** (есть в демо на наборе
«Демо-подрядчик»), **нет** (в коде нет, на сайте только как граница или план).

Главный вывод N0: статуса «заказчик» нет ни у одной функции. `docs/BACKEND_HANDOFF.md`
(строки 22-24): «Рабочей базы нет. Живой адрес работает в демо-контуре». Данные /gas живут
в localStorage. Заказчик видит свой недельный отчёт по личной ссылке `/gas?c=…`
(`src/server/customer-data.ts`) с полосой «Тестовый режим». Поэтому учёт времени на сайте
подписан «Пилот у первого заказчика», а не «Работает у первого заказчика» (ADR-067, решение 2).

## Что на сайт не попало

Выработка на человеко-час, открытие в Google Таблицах, живой бот MAX, свои шаблоны документов,
строка сметы у суммы, распознавание голоса в демо (фраза заготовлена), хранение фото накладной
(в демо только имя файла). Всё это либо не написано, либо стоит границей «Чего ГАЙКА не делает».
