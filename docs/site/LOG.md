# Журнал «Сайт v2»

Задание: `docs/site/GAIKA_SITE_V2.md`. Ветка `feature/site-v2` от origin/main 0b30f4c.
Решения: ADR-067. Матрица: `docs/site/CAPABILITIES.md`.

## Task Brief

Сделать публичный сайт v2: главная по разделу 5, три страницы задач, кейс, разбор, демо,
политика, набор, 404; SEO одной переменной; снимки продукта; анимация; адаптив 360-1920.
Приложение (/gas, ГАЙКА, /office) не меняется. Расхождения с docs/gaika: GAIKA_CLAUDE.md
относит закупки к «не строить», а задание показывает «Снабжение» страницей задачи. Основание
выше (последнее указание основателя 11.11.2026): страница описывает то, что уже есть в демо
по ADR-057, и подписана «В демо».

Проверка этапов: быстрые ворота (типы, линтер, тесты, тексты, шкала) на каждом этапе,
полный `bun run ci` на готовых точках. Полный прогон идёт около 25 минут, на каждый из
десяти этапов его не хватает; где он не запускался, это записано строкой этапа.
