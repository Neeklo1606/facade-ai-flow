# 03. Оболочка и маршрутизация

Раздел встроен в существующее приложение, а не сделан отдельным: файловая маршрутизация
TanStack Start, макет `AppLayout`, та же шапка и меню.

| Файл | Что делает |
|---|---|
| `src/routes/gas.tsx` | Макет раздела: своя навигация `GasSectionNav` и `<Outlet />` |
| `src/routes/gas/*.tsx` | Экраны раздела |
| `src/routes/api/gas/export.ts` | Серверный маршрут выгрузки, POST |
| `src/lib/navigation.ts` | Пункт меню «Газ: учёт времени» |
| `src/lib/guide/screens.ts` | Названия и подсказки экранов: шапка и справка |

**Роли.** У направления свой набор: администратор, менеджер проверки, бригадир, руководитель.
Переключатель — в шапке раздела. Экран выбора роли ГАЙКИ на `/gas` не показывается
(`src/routes/__root.tsx`): два выбора роли подряд путают.

**Права.** Роль меняет меню и разрешённые действия. Это удобство показа: в рабочем контуре
права проверяет сервер, скрытый пункт меню защитой не является.

**Проверка.** `npx playwright test e2e/gas.spec.ts` — все десять экранов открываются
без ошибок в консоли.
