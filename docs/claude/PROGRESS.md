## Решения по ходу

1. Кеш `bun` был битый (`minimatch@3.1.5` без `brace-expansion`): `rm -rf ~/.bun/install/cache/minimatch@3.1.5*`
   и повторный `bun install`. Иначе `exceljs` не загружается.
2. `resolveJsonModule` включён в `tsconfig.json`: анонимизированный набор лежит JSON-ом,
   чтобы его правил только скрипт, а не человек.
3. Маршруты направления под префиксом `/gas/*`, а не в корне: в приложении уже есть `/login`,
   `/analytics`, `/users`, `/settings` со своим смыслом. Раздел получает свою навигацию.
