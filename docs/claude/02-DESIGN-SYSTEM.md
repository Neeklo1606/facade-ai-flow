# 02. Дизайн раздела

**Решение.** Раздел живёт в дизайн-системе EMBER текущего продукта, а не в отдельной
светлой теме из постановки. Так решил владелец: «реализуем на нашем текущем интерфейсе».
Требования постановки к виду при этом соблюдены.

| Требование постановки | Как сделано |
|---|---|
| Плотный B2B-интерфейс, без декора | Карточки EMBER, таблицы без зебры, ни одного градиента в разделе |
| Числа табличным начертанием, вправо | `tabular-nums` и `align: right` во всех таблицах и ячейках |
| Деньги «44 847 ₽», часы «6,58 ч», доходность «6 812 ₽/ч» | `fmtRub`, `fmtHours`, `fmtRate` в `domain/gas-ops/calc.ts` |
| Прочерк вместо нуля | Ячейки `MoneyCell`, `HoursCell`, `RateCell` показывают «—» |
| Мобильный первым, 375 px | Проверено e2e: ни на одном экране нет горизонтальной прокрутки страницы |
| Области нажатия от 48 px | Кнопки шагов бота `min-h-14`, действия проверки `min-h-12` |

**Деньги направления — целые рубли** (`amountRub`), а не копейки, как в остальной базе.
Отдельное имя поля и отдельный форматтер, чтобы не перепутать.

**Метки честности.** `SourceMark` стоит рядом со значением: «Факт» — перенесено из отчёта
заказчика, «Демо» — придумано для показа. `OutOfScopeNotice` — на экранах вне договора.
`StatusBadge tone="warn"` «Требует согласования» — там, где правило не согласовано.

Компоненты: `src/components/gas-ops/{GasSection,marks,EntryDetails,CustomerReport}.tsx`.
