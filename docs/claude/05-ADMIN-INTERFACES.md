# 05. Экраны менеджера и администратора

## `/gas/moderation` — очередь проверки (в договоре)

Вкладки по статусам: ожидает проверки, требует уточнения, черновики, отклонённые, все.
Карточка записи показывает три блока: что ввёл человек, что посчитала система, почему помечено.

Действия: подтвердить, отклонить с причиной, вернуть на уточнение, исправить время с
обязательным комментарием. Комментарий обязателен везде, кроме подтверждения. Любое решение
идёт в журнал действий; исправление пишет в историю «было → стало».

Подтверждение переносит запись в недельный отчёт и пересчитывает сводку — состояние одно.

## `/gas/entries` — журнал (в договоре)

Фильтры: бригада, статус, день, источник данных, поиск по номеру, объекту и бригаде.
Строка открывает карточку с расчётом и историей. Бригадир видит только свою бригаду и без сумм.

## `/gas/estimates` — стоимость работ (в договоре частично)

Подтверждённая стоимость без материалов: версия, источник, кто и когда подтвердил.
Ручной ввод суммы для объектов без сметы. Распознавание PDF-смет не делается — по ТЗ не входит.

## `/gas/admin` — настройка (**вне договора**, метка на экране)

Роли и что они могут, согласованные правила расчёта, десять открытых вопросов,
состояние подключений (ни одно не подключено), журнал действий.

## Критерии готовности

- решение без комментария не проходит там, где комментарий обязателен;
- подтверждение видно в журнале, в отчёте и в сводке сразу;
- бригадир не видит сумм ни на одном экране раздела.

Проверка: `npx playwright test e2e/gas.spec.ts --grep "сквозной сценарий"`.
