# 08. Проверка и передача

## Что запускается

| Команда | Что проверяет |
|---|---|
| `bun run typecheck` | Типы, два проекта TypeScript |
| `bun run lint` | eslint и prettier, включая запрет импорта домена в экраны |
| `bun test tests` | Домен, согласованность, негативные: 808 тестов, из них 41 по газу |
| `bun run scripts/audit-fact-report.ts` | Сверка анонимизированной выгрузки с итогами файла |
| `bun run scripts/check-gas-export.ts` | Выгрузка XLSX против расчёта, 27 сверок |
| `npx playwright test e2e/gas.spec.ts` | Десять экранов, сквозной сценарий, 375 px |
| `bun run scripts/gas-walk.ts` | Обход всех кнопок, ссылок и полей на 1440, 768 и 375 |
| `bun run scripts/gas-shots.ts` | 30 снимков с проверкой на персональные данные |
| `bun run ci` | Весь конвейер репозитория |

## Что проверяется в сквозном тесте

1. Каждый экран раздела открывается без ошибок в консоли.
2. Бригадир заводит запись → менеджер подтверждает → запись в журнале подтверждена →
   итог недели в отчёте изменился.
3. Дубль и пересечение не проходят, смена через полночь не вводится.
4. Предварительный отчёт помечен и больше утверждённого.
5. Выгрузка отдаёт файл `.xlsx`.
6. Сброс данных возвращает исходное состояние.
7. На 375 px ни на одном экране нет горизонтальной прокрутки страницы.

## Что проверяет обход `gas-walk`

На трёх ширинах: переполнение страницы, область нажатия от 44 px, подпись у каждой кнопки
и ссылки, отсутствие элементов за правым краем вне прокручиваемых контейнеров, ошибки
в консоли. На 1440 дополнительно нажимается каждая кнопка раздела: она обязана что-то менять —
адрес, разметку или появившийся слой. Кнопка без последствий это обещание, которого система
не выполняет. Последний прогон: 30 экранов, 534 элемента, 51 нажатие, замечаний нет.

## Перед показом заказчику

- `docs/source/` не в git: проверить `git status` перед коммитом.
- На скриншотах не должно быть реальных ФИО и адресов: данные анонимизированы на уровне
  скрипта, и он падает, если анонимизация не сработала.
- Метки «Демо: вне текущего договора» на `/gas` и `/gas/admin` не убирать:
  дашборд и админка в договор v1.0 не входят.
