# 06. Отчёт и выгрузка

## `/gas/reports`

**Формат заказчика.** Та же структура, что в его Excel: группа, бригада, сотрудник, строка
рамки смены, адреса. По каждому дню три показателя, затем «Итого». Уровни сворачиваются.
Строки без суммы, нулевые значения и аномалии видны.

**Аналитическая таблица.** Плоские строки: день, подразделение, бригада, сотрудник, объект,
вид работ, минуты, часы, сумма, доходность, статус, источник данных.

**Переключатель.** «Только подтверждённые» и «Предварительный». Предварительный помечен
полосой: в него входят записи, которые ещё не проверил человек.

## Инварианты (`src/domain/gas-ops/report.ts`)

1. Итог считается снизу вверх, из адресных строк. Числа из файла заказчика в расчёт не берутся.
2. Агрегат не складывается с детьми.
3. Сумма бригады не удваивается при нескольких сотрудниках.
4. В утверждённый отчёт идут только подтверждённые записи.
5. Строка без суммы остаётся без суммы: доходность — прочерк.

## Выгрузка XLSX

Собирается на сервере (`src/adapters/gas-ops/xlsx.ts`, маршрут `POST /api/gas/export`):
объединённые заголовки дней, группировка строк уровнями, итоги формулами `SUM`
по дочерним строкам, листы «Записи» и «Как считалось».

Доходность адресной строки записана значением (считается от минут), доходность итогов —
формулой от суммы и часов: на половине рубля расхождение в рубль, это описано в файле.
