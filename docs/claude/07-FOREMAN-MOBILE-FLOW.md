# 07. Экран бригадира

`/gas/foreman` — сценарий бота MAX на телефоне. Канал не подключён, и экран подписан как вид
бота, а не как работающий бот.

## Шаги

Главная → объект (только разрешённые, поиск) → дата (сегодня, вчера) → начало, окончание,
перерыв → проверка с рассчитанными минутами → подтверждение с номером записи и статусом.
Полный ввод — пять нажатий и два поля времени.

## Правила

- Бригадир вводит только время: сумм и видов работ он не вводит и не видит.
- Объект выбирается из списка закреплённых, свободного текста нет.
- Минуты показываются **до** подтверждения: «13:00 — 16:10, перерыв 0 мин, 190 мин = 3,17 ч».
- Несколько адресов за день — отдельная запись на каждый, кнопка «Внести ещё один адрес».
- До проверки запись можно исправить; возврат на уточнение бригадир отправляет сам.

## Ошибки ТЗ, п. 5.7

| Случай | Текст |
|---|---|
| Окончание раньше начала | «Смена через полночь в системе не ведётся» |
| Перерыв больше смены | «Перерыв больше смены. Проверьте значения» |
| Дубль | «По этому объекту за этот день запись уже есть» |
| Пересечение | «Время пересекается с записью ГЗ-… на N мин» |
| Объект не закреплён | «Этот объект не закреплён за вашей бригадой» |

Ошибки приходят из адаптера, а не из экрана: так же их будет отдавать сервер.
