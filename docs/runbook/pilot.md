# Пилот учёта времени на данных заказчика

Решение: ADR-069. Сервер в Docker: `docs/runbook/docker.md`. Здесь порядок от пустой базы
до первой принятой записи и проверка перед тем, как отдать ссылки людям заказчика.

## 1. Что нужно

- Сервер с Docker и домен (HTTPS ставит Caddy из compose).
- `deploy/.env`: `DOMAIN`, `GAIKA_MODE=server`, `POSTGRES_PASSWORD`, `SESSION_SECRET`,
  `CLIENT_LINK_KEY`, `APP_TIME_ZONE=Europe/Moscow`, `AUTH_CHANNEL=log`.
- Имена и телефоны: администратор, менеджер проверки, руководитель, бригадиры.
- Файлы заказчика: бригады и сотрудники, график недели, сметы объектов.

## 2. База и компания

```bash
docker compose --env-file deploy/.env up -d db
docker compose --env-file deploy/.env --profile tools run --rm migrate          # T3: «да» владельца
docker compose --env-file deploy/.env --profile tools run --rm migrate \
  bun run db:gas-init --name "Имя Фамилия" --phone "+79990000000" --group "1. Стальные" --url "https://$DOMAIN"
docker compose --env-file deploy/.env up -d --build app caddy
```

`db:gas-init` пишет пустую компанию без демо-данных и печатает ссылку администратора
на 72 часа. Повторно команда не сработает: компания заводится один раз.

## 3. Люди

Администратор входит по ссылке и загружает бригады и сотрудников: «Данные» → «Бригады из Excel»,
«Сотрудники из Excel». После этого заводятся остальные:

```bash
R="docker compose --env-file deploy/.env --profile tools run --rm migrate bun run db:gas-user"
$R --name "Менеджер"   --phone "+79990000001" --role manager  --url "https://$DOMAIN"
$R --name "Руководитель" --phone "+79990000002" --role director --url "https://$DOMAIN"
$R --name "Бригадир 1" --phone "+79990000003" --role foreman --brigade "Бригада 1" --url "https://$DOMAIN"
```

Каждая команда печатает ссылку первого входа. Передать её человеку лично или в мессенджере.
Бригадир без бригады в справочнике не заводится: команда называет причину.

| Роль     | Что делает                                                 |
| -------- | ---------------------------------------------------------- |
| admin    | справочники, роли, всё остальное                           |
| manager  | объекты, график, сметы и формула, проверка записей         |
| director | неделя, закрытие недели, выгрузка Excel                    |
| foreman  | ввод времени своей бригады на «Сегодня» и в боте, без сумм |

## 4. Первая неделя

1. Менеджер: «Объекты» → «Добавить объект» или график недели из Excel.
2. Менеджер: «Сметы» → «Загрузить смету», привязать к объекту, «Подтвердить смету».
   «Настроить» — какие строки сметы идут в стоимость работ.
3. Бригадиры вносят время с телефона: `https://$DOMAIN/gas`, «Сегодня» или бот на экране.
4. Менеджер: «Проверка» → «Принять» или «Исправить» с причиной.
5. Руководитель: «Табель» → «Выгрузить» → «Excel утверждённый»; «Неделя» → «Закрыть неделю».

«Сегодня» и неделя идут по часам сервера в `APP_TIME_ZONE`: неделя понедельник–суббота
сменяется сама. Прошлые недели остаются в базе и в выгрузке.

## 5. Проверка перед пилотом

На копии сервера или локально, на пустой базе, в таком порядке:

```bash
createdb gaika_pilot
export DATABASE_URL="postgres://localhost/gaika_pilot?sslmode=disable" SESSION_SECRET="…" APP_TIME_ZONE=Europe/Moscow
bun run db:migrate
bun run db:gas-init --name "Соколов Артём" --phone "+79210000000" --group "1. Стальные" --url http://localhost:4700
bun run db:gas-user --name "Иванова Ольга" --phone "+79210000001" --role manager --url http://localhost:4700
bun run db:gas-user --name "Козлов Пётр" --phone "+79210000002" --role director --url http://localhost:4700
NITRO_PRESET=node-server bun run build --mode server
PORT=4700 AUTH_CHANNEL=log node .output/server/index.mjs &
PILOT_ADMIN="…" PILOT_MANAGER="…" PILOT_DIRECTOR="…" npx playwright test -c playwright.pilot.config.ts
```

Прогон входит по трём ссылкам в отдельных окнах, загружает бригады, сам заводит бригадира,
проходит объект, график, смету, формулу, ввод в боте, проверку и выгрузку и сверяет в файле
105 000 ₽ и отсутствие демо-объектов. Ссылки одноразовые: на повтор нужна новая база.

## 6. Что пока вручную или не подключено

- Люди заводятся командой, а не экраном: экрана приглашений в `/gas` ещё нет.
- Вход по коду только `AUTH_CHANNEL=log`: код виден на экране входа. Для пилота с
  сопровождением это допустимо; SMS или Telegram — решение владельца.
- Бот MAX: вебхук отвечает 501 до токена и проверки канала. Бригадир вводит время в вебе.
- Исходные файлы смет и графиков не хранятся, только разобранные итоги.
- Агент-чат без `ANTHROPIC_API_KEY` отвечает правилами.
- Одна компания на базу.
