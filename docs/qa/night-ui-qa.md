## Осталось и почему

- Обходчик не меряет контраст: тёмную плитку на стекле нашёл ручной проход. Нужна отдельная
  проверка контраста по экранам ролей (axe есть в `fixtures.ts`, на газовые экраны 390 не
  вызывается).
- «Сметы» на телефоне: две кнопки загрузки, «Выбрать файлы» (ADR-077) и «Загрузить смету»
  (мастер ADR-080). Объединение меняет решения ADR, без владельца не трогал.
- Менеджер после входа в демо попадает на старт-объяснение, а не в «Проверку»: так задумано
  для показа, путь в «Проверку» теперь одним касанием из шапки.
- Поля даты ПТО в безголовом Chromium показываются как mm/dd/yyyy: это формат браузера
  обходчика, на телефоне с русской локалью формат свой.
