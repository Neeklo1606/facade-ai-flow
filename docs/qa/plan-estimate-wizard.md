# План: пошаговая загрузка сметы, бригады, удобные правки

24.11.2026. Основание: запрос владельца, два звонка с заказчиком (`docs/customer/estimate-types.md`),
разбор кода (три входа загрузки, мастер без подтверждения стоимости).

## Что сейчас не так

1. **Три входа загрузки** с разным поведением: мастер «Загрузить смету» (объекты, обзор),
   «Папка смет» на странице смет и старый импорт с сопоставлением колонок под той же
   подписью «Загрузить смету». Непонятно, куда нажимать.
2. **Страница смет начинается с «Стоимость работ для выработки · согласовано»** — правило,
   к которому человек ещё не пришёл. Отвлекает от первого шага.
3. **Мастер не говорит, что это за смета** и какие разделы идут в отчёт. Земля, полиэтилен,
   «Субподрядные работы», «Корректировки для загрузки» показаны наравне со сталью и
   попадают в сумму работ объекта. Это и есть «данные берутся некорректно».
4. **Нет шага «Да, верно / Нет, исправить»**: значения показаны, но подтверждения нет,
   замечания разбора в мастере не видны, исправления только на другой странице.
5. **Стоимость подтверждается вне мастера**, после «Создать объект» мастер прыгает к бригадам.
6. **Ручной ввод** — шторка снизу, неудобно на компьютере.
7. **Бригады**: нельзя изменить название, удалить, привязать к объекту с экрана бригады;
   отпуск виден только на экране бригад.

## Решение

### Разбор (домен)

- Роль раздела по названию: **сталь** (в отчёт, СМР = итого − материалы), **испытания**
  (в отчёт отдельной строкой), **другие работы** (земля, полиэтилен — другие бригады),
  **не работы бригад** (субподряд, корректировки, пустой раздел).
- Тип сметы по набору разделов: «Сталь», «Сталь и испытания», «Подземный газопровод»
  (есть земля или полиэтилен: в отчёт только сталь, испытания — уточнить).
- Сумма работ объекта и «остаток по разделам» считаются только по разделам отчёта.

### Мастер загрузки: 5 шагов, назад и вперёд, шаг запоминается

1. **Файл** — только выбор файла и подсказка, какие сметы подходят. Ничего лишнего.
2. **Проверка** — «Смета типа …», шапка (объект, адрес, номер) и разделы отчёта: итого,
   материалы, СМР, чел.-ч с номерами строк. Замечания разбора. Кнопки **«Да, всё верно»** и
   **«Нет, исправить»**: исправление прямо в мастере, с причиной. «Загрузить другой файл»
   удаляет эту загрузку.
3. **Объект** — прикрепить к найденному, выбрать из списка (поиск) или создать из шапки.
4. **Бригады** — разделы отчёта бригадам; отпуск виден в списке; опрессовка — та же
   бригада отдельной строкой.
5. **Готово** — подтвердить стоимость прямо здесь; ссылки на объект, табель, смету.

### Страница смет

- Сверху одна кнопка «Загрузить смету» (мастер) и «Ввести вручную»; старый импорт с
  колонками убран из главного ряда.
- «Ждут подтверждения» и «Сметы по объектам» — папками по объекту с бригадами.
- Правило стоимости — ниже, свёрнуто, после списка смет.
- Шторка сметы: строки, которые берём в расчёт, подсвечены; выбор объекта с поиском.
- Ручной ввод — окно по центру, как в 1С.

### Бригады

- Изменить бригаду (название, подразделение, телефон), удалить бригаду без записей.
- Привязать бригаду к объекту из карточки бригады: объект и разделы галочками; снять.
- Отпуск: метка «в отпуске» в карточке, списке, выборе бригады в мастере и на объекте.

## Проверка

Домен и порт — тесты; мастер, страница смет, бригады — e2e на 1440 и 390; сверка на
реальных сметах из `.local` локально, без вывода сумм; полный `bun run ci`.
