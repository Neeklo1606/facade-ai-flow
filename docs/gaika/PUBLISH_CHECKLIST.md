# Публикация демо ГАЙКИ: чек-лист владельца

Шаг D6 (ADR-038). Публикация — класс T3: кнопку нажимает владелец.
main на GitHub: слияние 381e9bb (feature/gaika-polish, этап D, D0–D5), конвейер 12 шагов, код 0.

## 1. Lovable

1. Открыть проект в Lovable и убедиться, что синхронизация с GitHub подтянула main
   (последний коммит — «Слияние feature/gaika-polish…» или журнал D6 после него).
2. Нажать Publish. Сборка идёт по `.env.production`: контур `demo`, секретов в файле нет.

## 2. Переменные хостинга

| Переменная         | Нужна                   | Что делает                                                                |
| ------------------ | ----------------------- | ------------------------------------------------------------------------- |
| `DEMO_ACCESS_KEY`  | уже задана              | Ключ входа; без него адрес отвечает 401 (проверено 18.10.2026)            |
| `SESSION_SECRET`   | желательно              | Подпись куки персоны; без неё ключ подписи выводится из `DEMO_ACCESS_KEY` |
| `VITE_CONTACT_URL` | по желанию, до сборки   | Кнопка «Обсудить пилот» на финале; пусто — кнопки нет                     |
| `VITE_PUBLIC_URL`  | только при смене домена | Абсолютные адреса превью ссылки (og:image)                                |
| `AI_MODE`, ключи   | **не задавать**         | Живые модели и распознавание речи в этот показ не входят                  |

`VITE_*` читаются при сборке: после изменения нужен повторный Publish.

## 3. Ссылка для клиента

```
https://facade-ai-flow.lovable.app/?k=<ключ>
```

`?key=` тоже работает. После первого входа кука держится 30 дней, дальше ссылка без ключа.
Ключ в чат и в репозиторий не пишется.

### Ссылка для заказчика газа (ADR-044, F2)

```
https://facade-ai-flow.lovable.app/gas?k=<ключ>
```

Шлюз (`src/server.ts` → `grantResponse` в `src/lib/access.ts`) ставит куку и отвечает 302
на тот же путь без ключа: `/gas?k=…` → `/gas`, `/gas/guide?key=…&tab=calc` → `/gas/guide?tab=calc`.
Заказчик попадает на стартовый экран контура, а не на лендинг ГАЙКИ. Проверено тестом
`tests/domain/gas-start.test.ts` («ссылка заказчика /gas?k=КЛЮЧ»).

## 4. Проверка на телефоне за 2 минуты

1. Открыть ссылку: экран входа «Говорите с объекта», три плитки по «1 минута», тёмная тема.
2. «Смена → учёт»: кнопка микрофона → «Показать без микрофона» → «Готово» → касание
   «Объём: 96 м²» открывает фразу-источник → «Верно» → «Готово» и «Отменить».
3. «Дальше по сценарию»: на «Сегодня» есть 96 м².
4. «Дальше: ПТО → документ»: первым стоит отчёт «Стилобат» → «Принять» → скачать оба файла
   (сводка смены и черновик ведомости открываются как Excel).
5. «Дальше: Объект → снабжение»: тот же путь голоса → заявка «Кронштейн несущий, 40 шт»
   → во «Входящих» снабжения сдвиг вправо → «Принята»; «Глазами: прораб» — статус тот же.
6. «Итоги показа» → «Скачать файлы» → «Пройти заново» → снова экран входа.
7. Отправить ссылку себе в мессенджер: превью с новой картинкой ГАЙКИ, без FieldOps.

Если шаг ломается — снимок экрана и адрес страницы, остальное восстанавливается из лога.
