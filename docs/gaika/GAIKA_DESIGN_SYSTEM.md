# ГАЙКА AI: дизайн-система

Версия 2. Тёплая тёмная система с оранжевым светом. Развивает EMBER, а не заменяет его:
токены EMBER в коде переиспользуются и дополняются.
Фирменные цвета и знак ГАЙКИ официально не утверждены: это рабочая система для демо и пилота.

---

## 1. Характер

Дорогой рабочий инструмент: много воздуха, крупная типографика, мало элементов, тёплый свет.
Премиальность получается убиранием лишнего, а не добавлением эффектов.

Пять правил:
1. **На экране одна главная вещь.** Остальное тише.
2. **Свет это состояние.** Оранжевое свечение появляется на записи, главном действии и критическом сигнале.
   Если светится всё, не светится ничего, а на солнце экран перестаёт читаться.
3. **Воздух вместо линий.** Слои разделяются фоном и отступами, обводки только где без них не читается вложенность.
4. **Всё отвечает на касание.** Нажатие, перетаскивание, свайп, сдвиг дают мгновенный отклик.
5. **Простота важнее эффекта.** Если элемент не помогает действию, его нет.

## 2. Что берём из референсов

Закономерности, не экраны:

| Приём | Как в ГАЙКЕ |
|---|---|
| Цветовое поле сверху, уходящее в чёрный | Тёплое поле на «Сегодня», «Запись», «Ассистент» |
| Голосовая кнопка-капсула по центру снизу | Главный вход продукта |
| Белая капсула действия и круглая кнопка-стрелка | Главное действие экрана |
| Плитки с мягким свечением сверху | Три плитки сценариев на «Сегодня» |
| «Сдвиньте, чтобы подтвердить» | Только для необратимого |
| Точечная сетка на чёрном | Фон экрана записи и героя лендинга |
| Крупное приветствие и подсказки-карточки | Экран ассистента |

## 3. Две темы

**Тёмная:** демо, лендинг, вечер, диспетчерская руководителя.
**Светлая:** длинные списки, сводки, работа на улице днём. По системной теме, переключается вручную.
Печать и превью Excel всегда светлые.

## 4. Токены

```css
:root[data-theme="dark"] {
  /* Поверхности: тёплый чёрный, ступени еле заметны */
  --bg:            #0A0908;
  --bg-elevated:   #131110;
  --bg-raised:     #1B1816;
  --surface-glass: rgba(255,244,235,0.05);
  --line:          rgba(255,244,235,0.08);
  --line-strong:   rgba(255,244,235,0.14);

  /* Текст: тёплый белый */
  --text:          #F7F3EF;
  --text-2:        #A8A099;
  --text-3:        #6E6761;

  /* Свет */
  --ember:         #FF7A45;  /* запись, главное действие */
  --ember-hot:     #FF8F63;
  --ember-deep:    #C2410C;
  --ember-soft:    rgba(255,122,69,0.12);
  --sand:          #D9C3AB;  /* вторичный тёплый акцент, ИИ думает */
  --sand-soft:     rgba(217,195,171,0.10);

  /* Статусы, приглушены под тёплый фон */
  --ok:            #6FCF97;
  --warn:          #F2B84B;  /* нужно уточнить */
  --risk:          #FF5A5F;  /* критично */

  /* Главная кнопка */
  --pill-bg:       #F7F3EF;
  --pill-text:     #0A0908;

  /* Фирменный градиент: только герой лендинга и одна главная карточка экрана */
  --ember-gradient: linear-gradient(135deg, #0A0908 0%, #8F1D0B 35%, #F16001 68%, #D9C3AB 100%);
}

  --bg:            #F5F2EE;

  --line:          rgba(28,24,20,0.08);
  --line-strong:   rgba(28,24,20,0.14);
  --text:          #1C1814;

  --ember:         #D94A04;
  --ember-hot:     #E85002;
  --ember-deep:    #A8360A;
  --ember-soft:    rgba(217,74,4,0.10);
  --sand:          #9E8468;
  --sand-soft:     rgba(158,132,104,0.12);
  --ok:            #1F8A4C;
```

Контраст текста на статусах и на оранжевом проверяется автоматически, порог WCAG AA.

### Цвет сценария

Оттенок появляется только на плитке, чипе и шапке карточки своего типа:

| Сценарий | Оттенок | Свечение плитки |
|---|---|---|
| Отчёт | `--ember` | оранжевое сверху |
| Задача | `--sand` | песочное сверху |
| Проблема, риск | `--risk` | красное сверху |

## 5. Типографика

- Интерфейс: Inter Variable. Цифры, коды, единицы: tabular-nums.
- Моноширинный (JetBrains Mono) только для кодов, номеров и маркеров до двух слов.
- Шкала:
  - приветствие и герой мобильный 40/44, лендинг 56/60 и 72/76;
  - заголовок экрана 32/36 мобильный, 40/44 десктоп;
  - крупная цифра 48/52;
  - основной текст 17/24 мобильный, 15/22 десктоп;
  - подписи 14/20; служебный текст не мельче 13 px.
- Вес 400, 500, 600. Тонкие начертания запрещены. Трекинг -0.02em от 32 px.
- Капс только в коротких моноширинных маркерах.

## 6. Воздух и геометрия

- Сетка 4 px. Отступы: 8, 12, 16, 24, 32, 48, 64.
- Поля экрана: 20 px мобильный, 32-48 px десктоп. Между секциями 32-48. Внутри карточки 20-24.
- На мобильном экране максимум три карточки до прокрутки. Остальное ниже или в «Показать всё».
- Радиусы: поле 16, карточка 24, большая панель 32, шторка 28 сверху, капсула 999.
- Нажатие от 48 px, главная кнопка 56-64 px.
- Обводки почти не используются, слои различаются фоном.

## 7. Свет и движение

```css
--glow-ember:
  0 0 0 1px rgba(255,122,69,.30),
  0 0 32px rgba(255,122,69,.28),
  0 20px 70px rgba(241,96,1,.18);
--glow-sand: 0 0 36px rgba(217,195,171,.22);
--glow-risk: 0 0 28px rgba(255,90,95,.26);
```

| Состояние | Что происходит |
|---|---|
| Покой | Голосовая кнопка с лёгким тёплым свечением, остальное без света |
| Запись | Кнопка «дышит» `--glow-ember`, цикл 2 с, живая волна громкости |
| ИИ обрабатывает | Цветовое поле сверху медленно переливается в песочный, этапы текстом, спиннера нет |
| Подтверждено | Короткая зелёная вспышка до 600 мс и лёгкая вибрация, если устройство поддерживает |
| Критично | Статичное `--glow-risk` на одной карточке |

Интерактивность:
- Нажатие: сжатие до 0.97 за 120 мс и возврат. Только на касание, не на наведение.
- Шторки открываются пружиной, тянутся вниз для закрытия.
- Карточки проверки: свайп вправо подтверждает, влево возвращает, кнопки дублируют свайп.
- «Сдвиньте, чтобы подтвердить» только для необратимого.
- Длительности 160-280 мс, кривая cubic-bezier(.2,.8,.2,1).
- `prefers-reduced-motion` отключает дыхание, перелив и пружины.

## 8. Фирменные приёмы

**Цветовое поле.** Верх экранов «Сегодня», «Запись», «Ассистент»: тёплый радиальный градиент от `--ember-deep`,
уходящий в `--bg` к 45 процентам высоты. Поле меняется по состоянию: оранжевое в покое, песочное при обработке,
красное при критичном. Единственный большой градиент на рабочем экране.

**Голосовая кнопка.** Тёплая белая капсула 64 px по центру нижней панели, иконка волны, оранжевое свечение.
Касание открывает ввод, удержание сразу пишет. Во время записи раскрывается в панель: таймер, волна, «Пауза», «Фото», «Готово».

**Главное действие.** Капсула `--pill-bg` с текстом и круглая оранжевая кнопка-стрелка рядом.

**Нижняя панель.** Стеклянная: фон `--bg-elevated` с прозрачностью 80 процентов, размытие 20 px, без обводки.

**Плитки сценариев.** Три плитки: Отчёт, Задача, Проблема. Тёмная плитка, мягкое свечение сверху своим оттенком.

**Точечная сетка.** Точки 1 px, шаг 16 px, прозрачность 5 процентов. Экран записи и герой лендинга.

**Зерно.** Поверх фирменного градиента, прозрачность 4 процента.

## 9. Компоненты

| Компонент | Состояния |
|---|---|
| `VoiceCaptureButton` | покой, запись, пауза, нет сети, загрузка, обработка, ошибка, нет доступа к микрофону |
| `AmbientField` | покой, обработка, успех, критично, reduced-motion |
| `ScenarioTile` | отчёт, задача, проблема; покой, нажатие, неактивно |
| `PrimaryPill` | покой, нажатие, загрузка, неактивно |
| `EventCard` | источник, тип, факт одной строкой, статус, одно действие |
| `EntityChip` | объект, участок, человек, дата, вид работ |
| `AttentionDot` | янтарная точка с текстом причины, только у сомнительных полей |
| `SourceSheet` | фраза расшифровки, интервал аудио, фото, страница |
| `ApprovalCard` | что случилось, влияние, кто предлагает, что будет после |
| `SwipeReviewCard` | покой, тянется вправо, тянется влево, принято, возвращено, отмена |
| `SlideToConfirm` | покой, тянется, подтверждено, отменено |
| `SyncIndicator` | локально, в очереди, отправляется, сохранено, конфликт |
| `ResultList` | созданные сущности, исключение элемента, отмена |
| `EmptyState` | одно следующее действие |

## 10. Проверка

- Скриншоты 375, 390, 430, 1440 в обеих темах.
- Контраст AA автоматически.
- На рабочем экране один большой градиент и одно светящееся место в покое.
- Не больше трёх карточек до прокрутки на мобильном.
- Ни одного действия только по наведению, ни одного горизонтального переполнения.
- Реальный телефон, если доступен. Если нет, пометить «не проверено».
