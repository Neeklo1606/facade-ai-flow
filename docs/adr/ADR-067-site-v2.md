# ADR-067. Сайт v2: три задачи, страницы задач, SEO

Дата: 11.11.2026. Статус: принято. Основание: задание владельца `docs/site/GAIKA_SITE_V2.md`.
Связанные: ADR-047 (публичный сайт и данные), ADR-051 (заявки, превью), ADR-055 и ADR-065
(«Монохром»), ADR-058 (файлы ИД), ADR-059 (лендинг v1).

## Контекст

Главная v1 говорила абстрактно («данные превращаются в отчёты»), три модуля были одинаковыми
карточками, отдельных страниц задач не было, сайт был закрыт от поиска целиком. Покупатель
с телефона должен за 10 секунд понять три задачи, свою выгоду и первый шаг.

## Решения

1. **Структура.** Главная, три страницы задач по одному шаблону (`/uchet-vremeni-brigad`,
   `/snabzhenie`, `/ispolnitelnaya-dokumentatsiya`), кейс, разбор, демо, политика, набор
   партнёра, страница 404 сайта. Тексты в `src/lib/site/copy.ts`, переменные в `config.ts`.
2. **Статус учёта времени: «Пилот у первого заказчика»**, а не «Работает у первого заказчика».
   N0 показал: рабочей базы нет, заказчик смотрит свой отчёт по личной ссылке в демо-контуре
   (`docs/BACKEND_HANDOFF.md`, `docs/site/CAPABILITIES.md`). Правило 3.2 задания разрешает
   менять статус по коду. Владелец меняет строку в `copy.ts`, когда появится рабочий контур.
3. **Фразы поправлены по коду** (раздел 5.5 задания разрешает замену): «правка после закрытия
   только через переоткрытие с причиной» вместо «исправление после закрытия с причиной»;
   «у суммы записи видно источник: смета, её версия и кто подтвердил» без строки сметы;
   «сравнение предложений на одном экране» вместо «в одной таблице»; выработка на
   человеко-час не обещается (считается, но не показана); Google Таблицы «проверим в пилоте»;
   свои шаблоны документов «пока нет». В кейсе бригадир вносит время «с телефона», не
   «в мессенджере»: бот MAX не подключён, он записан границей.
4. **SEO одной переменной.** `SEO_INDEX=on` открывает `/`, три задачи, `/case/gas`, `/razbor`,
   `/demo`, `/privacy` (`INDEXABLE_PATHS` в `src/lib/site/paths.ts`). Мета robots, заголовок
   `x-robots-tag` (`src/server.ts`) и `robots.txt` решаются одной функцией `isIndexablePath`.
   `robots.txt` и `sitemap.xml` отвечает сервер (`src/routes/robots[.]txt.ts`,
   `sitemap[.]xml.ts`), статичный `public/robots.txt` удалён. Без `SEO_INDEX` всё как было:
   `Disallow: /`, `sitemap.xml` отвечает 404.
5. **Решение об индексации во вкладке.** Сервер кладёт мету `gaika-seo`, вкладка читает её
   один раз. Раньше после загрузки скриптов мета robots сменилась бы на noindex.
6. **lastmod карты сайта** берётся из `VITE_BUILD_DATE`, без неё из времени запуска сервера.
   `vite.config.ts` не меняем: файл общий с Lovable.
7. **JSON-LD:** Organization (только имя и адрес), SoftwareApplication без рейтинга и цены,
   FAQPage с теми же текстами, что на странице, BreadcrumbList на страницах задач.
8. **Страница 404 сайта.** Адрес, первый сегмент которого не принадлежит приложению
   (`APP_SEGMENTS` в `paths.ts`), рисуется оболочкой сайта со статусом 404. Тест
   `tests/site/paths.test.ts` сверяет список с папкой `src/routes`. Неизвестные адреса внутри
   приложения (`/gas/…`, `/office/…`) ведут себя как раньше.
9. **Заявка.** Необязательное поле `task` (time, supply, docs) и источники `task-time`,
   `task-supply`, `task-docs` в порту `LeadSink`. Старые заявки без поля проходят.
10. **Меню телефона** на Radix Dialog: фокус внутри, Escape, фон не прокручивается; «назад»
    закрывает шторку через запись в истории.

11. **Снабжение и документы в демо.** В публичной сборке они за флагом газового контура
    (ADR-061, `gaika-gas-only`): посетитель их не увидел бы, а сайт говорит «В демо».
    Плитки «Снабжение объекта» и «Исполнительная документация» на `/demo` снимают флаг
    на сессию вкладки ключом, которым их открывают сквозные тесты, и ведут к выбору роли.
    Сборка, `/gas` по прямой ссылке и личный контур заказчика не меняются. Основание:
    последнее указание владельца 11.11.2026 выше заморозки 03.11.2026.
12. **Снимки продукта** снимает `scripts/site-shots.ts` на ширине 1440 (оболочка /gas на 1280
    сжимает заголовок экрана) и 390, deviceScaleFactor 2. Это настоящий интерфейс «Газ v4»
    с его оранжевым: сайт остаётся монохромным, цвет есть только в снимках продукта.

## Файлы вне папок сайта

Задание (раздел 14) разрешает только файлы сайта. Затронуты общие файлы, все по делу сайта:
`src/routes/__root.tsx` (страница 404 сайта вместо экрана приложения для адресов сайта),
`src/server.ts` (правило `x-robots-tag`), `src/lib/access.ts` (`/sitemap.xml` проходит шлюз
так же, как `/robots.txt`), `src/ports/leads.ts`, `src/adapters/leads/index.ts`,
`src/ports/analytics.ts` (порты заявок и аналитики сайта, ADR-051). Экраны /gas, ГАЙКИ
и /office, domain и адаптеры приложения не менялись.

## Последствия

Владелец задаёт `SEO_INDEX=on`, `VITE_PRICE_PILOT`, `VITE_CASE_STATUS`, коды подтверждения
поисковиков до Publish. Когда появится рабочий контур у заказчика, статус учёта времени
меняется одной строкой.
