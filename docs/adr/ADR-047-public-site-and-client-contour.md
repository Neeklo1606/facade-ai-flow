# ADR-047. Публичный сайт, демо-вход и личный контур заказчика

Дата: 23.10.2026. Статус: принято. Основание: docs/launch/01_SPEC.md, разделы 3 и 6;
аудит L0 (docs/launch/audit/ROUTES.md, DATA.md, J1.md).

## Task Brief

Цель: ссылку можно пересылать любому подрядчику. По ней открывается сайт, а не приложение;
из сайта два касания до первого шага показа; в публичном контуре нет ни названия, ни цифр
газового заказчика. Заказчик продолжает видеть своё по личной ссылке.

Меняется: маршрут `/` (был вход демо ГАЙКИ), новые `/demo`, `/case/gas`, `/razbor`, `/kit`,
`/privacy`; источник данных /gas; бренд /gas; новый шаг конвейера. Не меняется: расчёт
domain, правила, фикстуры «Северной Короны», экраны ГАЙКИ, рабочий контур (`VITE_DATA_SOURCE=server`).

Класс T2. Расхождения: 01_SPEC 6.1 называет ОБ-200 синтетическим, но он стоит в реальном
населённом пункте файла заказчика. В публичном наборе он переезжает в вымышленный.
Указание владельца 23.10 «дизайн премиальнее, проще, удобнее на мобильном» учитывается
в каркасе сайта: одна колонка, крупная типографика, одна главная кнопка на экран.

## Решение

### 1. Поверхности

| Адрес | Поверхность | Оболочка |
|---|---|---|
| `/`, `/case/gas`, `/razbor`, `/kit`, `/privacy` | публичный сайт | `SiteLayout`: шапка 56, контент, подвал |
| `/demo` | вход в демо | `SiteLayout` |
| `/gas/*` | учёт выработки | `GasShell` (ADR-044) |
| остальное | ГАЙКА, `/office` | `AppLayout`, `OfficeLayout` |

Сайт рендерится на сервере целиком: первый HTML несёт текст, кнопки и мета-теги, заставка
`boot-splash` на сайте не выводится. Корневой загрузчик для страниц сайта ничего не запрашивает
(сотрудники, справочники и часы нужны только приложению). `RolePicker` на сайте не монтируется.

Экран входа ГАЙКИ уходит с `/` на `/demo` вторым блоком. Плитки сценариев вынесены
из `RolePicker` в `DemoScenarioList` без изменения поведения: те же сценарии, роли, переходы.
`RolePicker` остаётся выбором роли поверх экранов ГАЙКИ и получает ссылку «К демо» на `/demo`.

В рабочем контуре (`VITE_DATA_SOURCE=server`) `/` по-прежнему ведёт на рабочий экран роли:
сайт существует только в демо-сборке.

### 2. Разосланные ссылки

| Было | Стало |
|---|---|
| `/` | сайт; с него «Открыть демо» ведёт на `/demo` |
| `/gas` | старт показа учёта выработки, как раньше, на публичном наборе |
| `/?k=`, `/?key=`, `/gas?k=` | шлюз ключа (`DEMO_ACCESS_GATE`), выключен; при включении ведёт себя как раньше |
| `/today`, `/capture`, `/check` и др. без роли | выбор роли со ссылкой «К демо» |

Параметра показа на `/` (`?show=`) в разосланных ссылках не было: проверены PUBLISH_CHECKLIST,
DEMO_SCRIPT, RUNBOOK и код (`src/lib/access.ts`, `src/lib/guide/screens.ts`).

### 3. Данные

- **Публичный набор «Демо-подрядчик»** строит `scripts/make-public-dataset.ts` (`bun run data:public`)
  из набора заказчика с фиксированным seed: вымышленные населённые пункты с приставкой «Демо-»,
  суммы с множителем 0,7-1,3 на объект и округлением до 50 ₽, итоги и доходность пересчитаны
  из записей, структура недели, бригады, группы и интервалы сохранены. Результат
  `src/data/mock/public/fact-report.public.json` лежит в git.
- **Сид /gas параметризован**: `buildSeedFrom(report, place)` строит одно и то же состояние
  из любого набора. Демо-объекты сценариев (ОБ-101, 102, 103, 200) получают населённый пункт
  из параметра. ОБ-200 сохраняет 14 700 ₽, 2,50 ч, 5 880 ₽/ч.
- **Клиентский код импортирует только публичный набор.** Набор заказчика импортируют серверный
  модуль `src/server/client-contour.ts`, тесты domain и скрипты сверки.
- **Бренд /gas — функция контура**: `public` → «Демо-подрядчик», `client` → название заказчика,
  приходит с сервера вместе с набором.

### 4. Личный контур заказчика

- `/gas?c=<CLIENT_LINK_KEY>` обрабатывается в `src/server.ts` до рендера: при совпадении ставится
  кука `gaika_client` на 30 дней (`HttpOnly; SameSite=Lax; Secure` на https) и ответ 302 на тот же
  путь без ключа, как `grantResponse` шлюза.
- Значение куки: HMAC-SHA256 от метки `gaika-client-contour-v1` с ключом, производным от
  `CLIENT_LINK_KEY`. Подпись сессии `session-token.ts` без `SESSION_SECRET` берёт случайный ключ
  на процесс, а у Lovable (Cloudflare) процессов много: кука жила бы до перезапуска изолята.
  Смена ключа гасит все выданные куки, это и есть отзыв доступа.
- Маршрут `/gas` получает контур загрузчиком через серверную функцию `gasContourFn`: без куки
  или без `CLIENT_LINK_KEY` ответ `{ kind: "public" }`, с верной кукой `{ kind: "client", brand, report }`.
  На сервере загрузчик выполняется при SSR, поэтому заказчик сразу видит своё.
- Состояние вкладки хранится отдельно по контуру (`neeklo-gas-ops-v1:public` и `:client`):
  записи показа на публичном наборе не смешиваются с данными заказчика.
- Блок «Сверка с вашим файлом» и раздел «Вопросы к согласованию» видны только в личном контуре.
- Без `CLIENT_LINK_KEY` личный контур выключен. Индексации нет: `x-robots-tag` на всех ответах.

### 5. Индексация и мета

`src/lib/site/config.ts` читает переменные 01_SPEC 13. `robots` = `noindex, nofollow`, пока
`SEO_INDEX` не равен `on`; `/kit` и /gas с личной кукой `noindex` всегда. Пока `SEO_INDEX` выключен,
заголовок `x-robots-tag` остаётся на всех ответах, как сейчас. `canonical` и `og:url` от `VITE_PUBLIC_URL`.

### 6. Проверка публичной сборки

`scripts/check-public-bundle.ts` после сборки демонстрации ищет в `.output/public/**`
и в HTML страниц сайта и /gas строки запретов: название заказчика, его населённые пункты,
итог недели в двух записях. Список строится в памяти из набора заказчика, в файлы не пишется.
Любое совпадение роняет конвейер. Шаг `check:public-bundle` стоит в `bun run ci` после
«Размер бандла: демонстрация».

## Последствия

- Цифры публичного /gas отличаются от файла заказчика. Сквозные тесты интерфейса сверяются
  с публичным набором (`e2e/gas-report-state.ts` берёт его сид), тесты domain по-прежнему
  проверяют набор заказчика.
- Данные заказчика остаются в git, а репозиторий публичный (аудит L0, DATA.md). ADR закрывает
  сайт, но не репозиторий: решение за владельцем (PLAN.md, вопрос 1).
- Если Lovable не умеет серверную функцию в превью редактора, превью покажет публичный набор:
  загрузчик падает в `public` при любой ошибке. Опубликованный адрес рендерится на сервере.

## Откат

Вернуть импорт `fact-report.ts` в `state.ts` и `GAS_BRAND` строкой, убрать шаг конвейера.
Маршруты сайта удаляются вместе с `SiteLayout`; `/` снова рисует `RolePicker` с `entry`.
