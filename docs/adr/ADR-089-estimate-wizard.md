# ADR-089. Пошаговая загрузка сметы, роли разделов, бригады из карточки

Дата: 24.11.2026. Основание: запрос владельца, звонки с заказчиком
(`docs/customer/estimate-types.md`), план `docs/qa/plan-estimate-wizard.md`.

## Контекст

- Три входа загрузки с разным поведением. На странице смет кнопка «Загрузить смету» открывала
  старый импорт с выбором колонок, а первым блоком шло правило стоимости.
- Мастер не говорил, что это за смета, и показывал все разделы как равные. «Субподрядные
  работы», «Корректировки для загрузки», земля и полиэтилен попадали в сумму работ объекта,
  хотя в отчёт выработки отдела идут только сталь и испытания.
- Не было шага «Да, верно / Нет, исправить», замечания разбора в мастере не показывались,
  стоимость подтверждалась на другой странице.
- Бригаду нельзя было изменить, удалить или привязать к объекту из её карточки.

## Решение

1. **Роль раздела по названию** (`domain/gas-ops/estimate-kind.ts`): сталь, испытания, другие
   работы, не работы бригад. **Тип сметы**: сталь; сталь и испытания; подземный газопровод
   (есть земля или полиэтилен — испытания отделу не относятся, помечено «уточнить»); тип не
   определён. Роль считается из названия, в базе ничего не хранится: схема не меняется.
   Сверено на 5 реальных сметах из `.local` (локально): типы совпали с описанием заказчика,
   итог и материалы совпали с расчётом из звонка.
2. **Сумма работ и остаток объекта** — только по разделам отчёта (и тем, где уже есть
   начисление). Начисление по доле раздела не меняется (ADR-078).
3. **Мастер на 5 шагов**: файл → проверка → объект → бригады → стоимость. Полоса шагов
   кликабельна назад, на каждом шаге «Назад». Проверка: тип сметы, шапка со строками файла,
   замечания разбора, разделы с СМР = итого − материалы, отчётные подсвечены и идут первыми.
   «Да, всё верно» отмечает замечания проверенными, «Нет, исправить» открывает правку итога
   раздела с основанием (ADR-066). Стоимость подтверждается на последнем шаге.
   Незаконченная проверка (объект ещё не выбран) запоминается во вкладке и продолжается.
4. **Страница смет**: сверху блок «Загрузить смету» (мастер). Старый импорт —
   «Импорт по колонкам» во втором ряду. Правило стоимости — после списка смет. Ручной ввод
   и формы бригады — окно по центру (`CenterDialog`), выбор объекта списком.
   В шторке сметы разделы отчёта подсвечены и подписаны ролью.
5. **Бригады**: `updateBrigade` (название уникально, код не меняется — по нему график и
   записи), `deleteBrigade` (только без записей времени; уходят состав, ставки, отпуск,
   назначения). Права: менеджер и администратор. В карточке бригады «Объекты бригады» и
   «Привязать к объекту» — объект и разделы галочками, отчётные отмечены сразу; отвязать
   крестиком. Отпуск виден в списке бригад, в выборе бригады в мастере и на объекте.

Строки испытаний внутри раздела стали (тип 1) по-прежнему считаются по ADR-077, мастер
показывает их пометкой: как поступать, решает заказчик (вопрос 4 в `estimate-types.md`).
