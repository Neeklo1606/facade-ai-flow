# ADR-079: вид «Стекло» оболочки сервиса

Статус: принято. 21.11.2026. Запрос владельца: перенести эффект референса «Command Center»
(матовые стеклянные панели над интерьерной сценой) на админку сервиса, цвета подогнать под наш.

## Решение

1. **Слой поверх «Тепла», а не новые компоненты.** `src/styles/gas-glass.css` подключён сразу после
   `gas-warm.css` и работает только при `data-glass` на `<html>`. Экраны не переписываются: стекло
   берут существующие классы оболочки (`gas-topbar`, `gas-sidenav`, `#gas-main`, `mono-tabbar`)
   и поверхностей (`surface-1`, `card-v3`, `mono-card`, `warm-tile`, `warm-kpi`).
2. **Два уровня токенов.** На `<html>` сплошные кремовые (тёмная тема: шоколадные) цвета: окна,
   шторки и подсказки в порталах остаются плотными и читаемыми. Внутри `.gas-shell` поверхности
   полупрозрачные; псевдонимы `--surface`, `--text`, `--accent` задаются заново, потому что var()
   на корне вычисляется один раз.
3. **Элементы референса.** Сцена-интерьер на фоне (окно с переплётом, проём, пол, пятно света,
   CSS без картинок; фото можно подложить `--glass-photo`). Шапка капсулой, меню плавающей колонной
   с кремовым активным пунктом, контент на матовом листе радиусом 34 с бликом по краю, карточки
   с внутренней подсветкой, переключатели с тёмной выбранной капсулой, нижний док на телефоне.
   Появление карточек и рост столбцов, печать заголовка.
4. **Наш цвет.** Зелёная «главная» плитка референса заменена терракотовой: первая плитка
   `KpiStrip` (класс `kpi-strip`) и `warm-kpi`. Серии графиков: графит, зелёный, терракота, охра.
   Главная кнопка остаётся `--flame`.
5. **Выбор вида.** «Стекло» по умолчанию, «Тепло» в профиле, раздел «Вид»
   (`src/lib/gas-ops/glass.ts`, ключ `gaika-gas-look` в localStorage). Вне `/gas` атрибута нет.
6. **Доступность.** «Уменьшить прозрачность» в системе: панели плотнее, без размытия, сцена остаётся.
   Повышенный контраст и принудительные цвета: сплошные поверхности без сцены. «Уменьшить движение»
   выключает анимации. Серые подписи `--ink-3` темнее, чем в «Тепле»; контраст подписей замерен
   по пикселям снимков на 10 экранах в обеих темах.
7. **Геометрия ADR-061 не меняется.** Рамки шапки (56 во всю ширину), меню (240 от левого края)
   и нижней панели прежние: капсулы и матовый лист рисуются псевдоэлементами `::before` внутри них.
   `backdrop-filter` только на псевдоэлементах: на самом `<main>` он сделал бы его опорой для
   `position: fixed` (липкая панель решений, шторки). Появление карточек без сдвига
   (прозрачность и размытие): тесты меряют высоты и положение сразу после загрузки.
8. **Шрифт.** Manrope из референса не подключён: остаётся Golos Text (кириллица, свой хостинг,
   без роста бандла).

## Попутно найдено

Lightning CSS при порядке `backdrop-filter`, затем `-webkit-backdrop-filter` оставляет только
префиксную строку, которую Chrome не понимает. В новом файле префикс идёт первым. В `styles.css`
у шапки и нижней панели телефона «Тепла» тот же порядок: матовость там сейчас не работает.
