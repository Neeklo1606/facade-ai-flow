# ADR-046. Выдвижная навигация телефона

Дата: 22.10.2026. Статус: принято.

## Task Brief

Сохранить существующие разделы и роли, сделать мобильное меню доступной выдвижной панелью и улучшить читаемость текста. Компьютер и планшет сохраняют текущую оболочку. Git fetch не выполняется: состоянием Git управляет Lovable. D6 и публикация вне задачи.

## Решение

Использовать существующий SidebarInner внутри Radix Dialog на телефоне: удержание фокуса, блокировка фоновых действий, закрытие по Escape, фону и переходу. Подписи переносятся, область касания не меньше 48 px. Размеры мобильного текста и панели задаются общими семантическими токенами; масштаб компьютера не меняется.

## Проверка

Проверить открытие, закрытие, переход, возврат фокуса и отсутствие переполнения на телефоне; сохранить поведение desktop. Физический телефон и публикация не входят в проверку.
