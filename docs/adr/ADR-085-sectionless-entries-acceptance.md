# ADR-085: запись без раздела на объекте с разделами не получает долю всей сметы

Статус: принято. 23.11.2026. Ночная приёмка заказчика П6 (`docs/qa/CRITICAL_TEST_PLAN.md`,
`e2e/acceptance-gas.spec.ts`). Меняет ADR-078, п. 10.

## Контекст

ADR-078, п. 10: записи без раздела считаются «по-прежнему», то есть долей подтверждённой стоимости
объекта по минутам всех записей. На объекте, смета которого разбита на разделы, это второе начисление
тех же денег: раздел 3 начислен по доле целиком, а запись бригады без назначения на том же объекте
получала ещё долю всей сметы по минутам (в приёмке 7 263 ₽ сверх стоимости раздела). Повторное
подтверждение сметы раздавало долю и подтверждённым записям без суммы. Пункт чек-листа заказчика
«частичное выполнение без двойного начисления» не выполнялся.

## Решение

1. `splitBySections` (domain, `section-accrual.ts`): режим «по доле» и у объекта есть раздел со
   стоимостью работ. Тогда стоимость объекта начисляется только по разделам.
2. Запись без раздела на таком объекте при принятии получает часы, но не сумму (`shareOf` даёт null).
   В карточке проверки «Сумма не рассчитана · раздел записи не указан» и подсказка назначить бригаде
   раздел. Автопилот такую запись не принимает: суммы нет, решает Оксана.
3. Подтверждение сметы и смена правила на таком объекте не раздают стоимость по минутам
   (`applyCost` пропускает `recalcObject`).
4. Режим «по времени» и объекты без разделов считаются как раньше.

## Проверка

- `tests/negative/gas-section-accrual-flow.test.ts`, «запись без раздела на объекте с разделами»:
  без исправления падает (получено 7 529 ₽ вместо null), с исправлением начислено по объекту ровно
  стоимость раздела; режим «по времени» по-прежнему даёт долю.
- `e2e/acceptance-gas.spec.ts` на 1440 и 390: «Сумма не рассчитана», в утверждённом Excel строка
  с 480 минутами без суммы.

## Открытый вопрос к Оксане

Как начислять работу бригады без назначения на объекте с разделами: назначить раздел задним числом
(сейчас: назначение на странице объекта, затем новая запись) или отдельной статьёй вне сметы.
