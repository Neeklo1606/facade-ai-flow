# ADR-052. Дизайн-система «Графит»: токены, шрифт, кнопки

Дата: 25.10.2026. Статус: принято. Основание: задача владельца «ГАЙКА Графит + расчёт по сметам»
от 25.10.2026, разделы 2, 3 и 5.

## Task Brief

Цель: спокойная графитовая основа, тёплый оранжевый акцент ГАЙКИ для действия, яркая палитра
данных, свой шрифт с кириллицей без обращения к Google Fonts и один набор кнопок на все экраны.
Меняются: `src/styles.css` (токены обеих тем), `src/components/ui/button.tsx`, подключение
шрифта в `src/routes/__root.tsx`, `public/fonts`, ворота `check:typography` и новый скрипт
контраста. Не меняются: шкала размеров ADR-045, раскладка экранов, данные, расчёт. Класс T2.

**Расхождения.** Документ `GAIKA_DESIGN_SYSTEM_V4.md` в загрузках владельца не найден (поиск
по `~/Downloads`, `~/Desktop`, `~/Documents` по имени). Работа идёт по разделам 2-5 задачи,
где значения токенов, шрифта и кнопок заданы полностью. Разделы V4, на которые задача
ссылается без значений (точные размеры спарклайнов, раздел 6 V4 с порогами), не выдумываются:
в отчёте они отмечены как непроверенные.

## Решение

### 1. Токены

Новые имена: `rail`, `canvas`, `panel`, `panel-2`, `panel-3`, `line`, `line-2`, `ink`, `ink-2`,
`ink-3`, `accent`, `accent-hover`, `on-accent`, `accent-soft`, тоны `mint`, `amber`, `coral`,
`sky`, `lavender`, `periwinkle`, `teal`, `pink`. Значения тёмной темы из таблиц раздела 2.1
задачи, светлой по логике V4 из той же задачи. Прежние имена (`void`, `surface`, `text-2`,
`orange`, `ok`, `warn` и другие) остаются псевдонимами новых: экраны перекрашиваются без
правки разметки. Метка: фон тон + альфа 16 %, текст тоном. Серии графиков: mint, sky, lavender,
teal, pink, periwinkle; amber и coral в графиках не используются.

Контраст проверяет `scripts/check-contrast.ts` (входит в `bun run check:typography`): каждая
пара текст / фон в обеих темах от 4,5:1, значки и границы полей от 3:1. Метки считаются
на своей прозрачной плашке поверх `panel` и `panel-2`. Значение, которое не проходит,
поправляется по светлоте с сохранением оттенка, поправка записана комментарием у токена.

### 2. Шрифт: Golos Text

Сравнение Onest 5.x и Golos Text 5.3 (fontsource, OFL) по трём проверкам задачи:

| Проверка                 | Onest                                             | Golos Text           |
| ------------------------ | ------------------------------------------------- | -------------------- |
| Табличные цифры (`tnum`) | есть, столбцы ровные                              | есть, столбцы ровные |
| Различимы 1, l, I        | l и I почти одинаковые палочки (ширины 219 и 261) | у l хвост, I прямая  |
| Различимы 0 и O          | 0 уже O (665 и 761)                               | 0 уже O (620 и 740)  |
| Веса 400, 500, 600       | есть                                              | есть                 |

Выбран **Golos Text**: только у него строчная l отличается от прописной I, а это коды
бригад, номера записей и адреса. Снимок сравнения сделан на 28 px на тёмном фоне.

Подключение:

- самохостинг woff2 из пакета `@fontsource/golos-text` 5.3.0 в `public/fonts`: подмножества
  `latin`, `latin-ext` (в нём знак ₽), `cyrillic`, веса 400, 500, 600;
- `font-display: swap`, `preload` для `cyrillic-400` и `latin-400`;
- запасной `Golos Fallback` на Arial с `size-adjust`, `ascent-override`, `descent-override`,
  посчитанными по метрикам Golos (UPM 1000, ascent 980, descent 220, средняя ширина 556);
- обращение к `fonts.googleapis.com` убрано. Моноширинный шрифт берётся системный
  (`ui-monospace`): JetBrains Mono нужен был только для кодов, а внешняя загрузка роняла
  сквозные тесты без сети (25.10.2026, 32 ложных падения).

### 3. Кнопки

Один компонент `Button`, варианты раздела 2.3 задачи:

| Вариант                                       | Вид                                                                                                                 |
| --------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| `primary`                                     | таблетка, заливка `accent`, текст `on-accent` 15/600, иконка справа в круге 24 с фоном `on-accent` 14 % (`iconEnd`) |
| `secondary` (`outline`, `default` псевдонимы) | таблетка, фон `panel-2`, граница `line-2`, текст `ink`                                                              |
| `quiet` (`ghost` псевдоним)                   | текст `ink-2` без фона, при наведении фон `panel-2`                                                                 |
| `destructive`                                 | текст `danger` без заливки                                                                                          |
| `size="icon"`                                 | круг 40 (телефон 44), фон `panel-2`, граница `line`                                                                 |

Высоты: компьютер 40, телефон 44, `size="field"` и решение по записи 52, голосовая 56.
Нажатие `scale(0.97)` за 100 мс, фокус кольцом `accent` 2 px с зазором 2 px. Загрузка:
подпись меняется на `loadingText`, ширина держится основной подписью. Свои классы цвета
и формы кнопок в экранах запрещены новым правилом `check:typography` (литералы цвета
и произвольные размеры в новом коде).

## Последствия

- Все экраны меняют вид сразу: псевдонимы ведут на новые значения. Сквозные тесты,
  которые сверяют цвета, обновляются по смыслу (значение, а не проверка).
- Сквозные тесты больше не зависят от Google Fonts.
- Отказ: вернуть `src/styles.css`, `button.tsx` и `__root.tsx` из `main` одной командой
  `git checkout main -- <файлы>`; данные и расчёт это не затрагивает.
