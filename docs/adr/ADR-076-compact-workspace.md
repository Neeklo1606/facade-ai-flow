# ADR-076: компактные рабочие данные и визуальные пометки

Статус: принято. 17.11.2026.

Сохраняем порт данных, роли, историю решений и расчёт принятых часов. Обновляем общие компоненты и семантические токены. Из визуальных референсов используем контраст, тёплый акцент и небольшие карточки; читаемость таблиц приоритетнее декоративных эффектов.

Пустая дата означает отсутствие ограничения, а не текущую дату браузера. Пользователь явно видит диапазон записей и может выбрать неделю отчёта. Фильтр не меняет данные.

Цветовая пометка — личное оформление ячеек, сохранённое в браузере с ключами контура, строки и колонки. Не заменяет статус принятия, не меняет деньги и не входит в утверждённый Excel. Сбой сохранения показывается, успех не имитируется. Очистка применяется только к выделению.

Неделя использует существующие агрегаты только принятых записей, без новых формул. Управление бригадами повторно использует существующие действия и права. Не добавляем фиктивное подключение MAX, AI или VPS.

Кнопки решения раскрытой карточки расположены перед длинными замечаниями: проверяющий может сразу открыть исправление. Отправка на уточнение, причины и проверка допустимости не меняются. Непринятая сумма помечена «К проверке», не «Начислено».

Первый замер демонстрационной сборки: 1028,6 КБ gzip против 1027,4 КБ предыдущего выпуска;
самый большой начальный кусок остался 109,4 КБ. Добавлены сохранение личных пометок и формы,
удалены анимация счётчика и высокий график. Дополнительных зависимостей нет. Порог общей
суммы обновляется по фактическому финальному замеру с запасом около 1 %; ограничение
самого большого куска 110 КБ сохраняется.

Финальные замеры: demo 1028,9 / 1040 КБ, server 972,2 / 982 КБ gzip; крупнейшие куски 109,4 и 108,3 / 110 КБ. Оба бюджета проверены.
